  • 11/12～11/13遭實際利用 🔥Check Point 防火牆零時差遭利用：駭客串連 PHP2Shell 拿到 root，再跳到 VMware ESXi 放「資料抹除」惡意程式 Check Point 11/12 發布緊急修補，修正 Gaia OS 的本機提權漏洞 CVE-2026-123039：以 root 執行的 DynamicCLI 服務聽在任何人都能寫入的本機 socket，卻不驗證連線者，登入後即可用 root 執行指令。Check Point 表示已觀察到約二十多個客戶遭攻擊。攻擊者先利用先前報過的 PHP2Shell 漏洞（CVE-2026-109618／109619）從 Mobile Access 入口進入，再用這個零時差提權，植入網頁後門、TSGA 後門與 TSProxy，最後橫向移到 VMware ESXi 主機執行抹除程式。第一波 10/30 起鎖定以色列組織，11/2 第二波擴及多國；部分現場留下政治訊息，研究人員懷疑可能是嫁禍。CISA 11/13 已列入已遭利用清單（KEV），聯邦機關限 11/16 前修補。 🔗 BleepingComputer（另見 SecurityWeek、The Hacker News、CISA KEV）↗
  • 11/13KEV 新增 💬CISA 將 UnrealIRCd 嚴重漏洞列入已遭利用清單：一般使用者就能以伺服器權限下指令 CVE-2026-114713（CVSS 8.6）出在 UnrealIRCd 處理 IRCv3「label」標籤時沒有跳脫換行字元，在兩台以上伺服器互連的 IRC 網路裡，任何一般使用者都能注入伺服器間指令，以伺服器／管理員權限踢人、封鎖等。維護者稱這是 UnrealIRCd 15 年來最嚴重的問題，11/7 已釋出 6.2.7.1 與免重啟熱修補 bundle-20261107，影響 6.0.0～6.2.7 與已停止支援的第 5 版。比利時 CCB 指維護者回報已遭實際利用，CISA 11/13 列入 KEV，限 11/16 修補；目前未公開攻擊者與受害者。 🔗 oss-security 維護者公告（另見 CISA KEV、比利時 CCB 公告）↗
  • 11/12～11/13重要修補 🗄️其他重要修補：PostgreSQL 一次修 52 個漏洞（含 22 年老 bug 可執行程式碼）；AMD 機密運算 SEV-SNP 新攻擊 Mior／Skyfall PostgreSQL 釋出 18.7、17.12、16.16、15.20、14.25，修補 52 個安全問題，其中 CVE-2026-6460（8.8 分）是型別混淆漏洞，能建立物件的資料庫使用者可在伺服器上執行程式，完整修補還需重新編譯已安裝的 C 語言擴充；研究員 Mehmet Ince 已公開部分利用細節，官方未回報遭攻擊。另外，ETH Zurich 等研究團隊公開 Mior 與 Skyfall 兩種攻擊，惡意雲端主機在控制 hypervisor（Mior 還需控制 BIOS）的前提下，可讀取 AMD SEV-SNP 機密虛擬機內的秘密；修補在主機韌體端，租用機密 VM 的客戶只能等雲端業者更新。 🔗 The Hacker News（PostgreSQL 與 AMD SEV-SNP 兩篇報導）↗
