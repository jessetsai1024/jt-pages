  • 11/26工程🦀Anthropic 把 Messages API 從 Python 改寫成 Rust，由 Claude 代理群負責驗證官方工程文章說，API 流量從 2024 初到 2026 秋成長約 1,800 倍，於是讓 Claude 改寫核心請求路徑，並把正式上線的 Python 服務當成驗證器，在真實流量上比對差異、自動派代理修正。改用 Rust 後每個請求 CPU 用量少約 70%、首 token 中位延遲快約 20%，全程沒有停機。🔗 Anthropic 官方（＋@AnthropicAI、@ClaudeDevs）↗
  • 11/25安全研究🧠Anthropic Fellows 研究：回頭用「神經元」做可解釋性研究改看每個神經元對輸出的貢獻，而非只看什麼讓它被觸發，發現過去放棄神經元的三個理由（一個神經元混多種概念、跨層意義改變、知識太分散）都比想像中小。第二篇示範不必額外訓練，就能用開放權重模型的神經元偵測有害文字、引導行為、找出微調模型的隱藏行為。🔗 Anthropic Alignment 官方（＋@AnthropicAI）↗
