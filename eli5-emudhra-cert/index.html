🏛️ 憑證和 CA 是什麼？

網站的「身分證」和「發證機關」

你連到銀行網站時，網站會拿出一張憑證，證明「我真的是這家銀行」。憑證要由憑證機構（CA）蓋章，瀏覽器只相信它認可的 CA。

CA 通常用「中繼憑證」幫網站蓋章，就像總局授權分局發證。eMudhra 是一家印度的 CA。

💥 發生什麼事？

8 個中繼憑證的「印章」被破解

eMudhra 有 8 個中繼憑證的私鑰（蓋章用的秘密）被找出來（Cloudflare、Bugzilla #0）。

Mozilla 的 Dennis Jackson 調查發現：這些 P-384 私鑰本該是超大的隨機數，結果全都小於 256——幾乎全是 0，只有最後一格有數字。所以幾乎一瞬間就能算出來（Bugzilla #5）。

這 8 把鑰匙都在 2025-04-30 同一批產生；其中 6 個用於網站 TLS（Chrome、Mozilla、Microsoft、Apple 都信任），2 個用於程式碼簽章（Microsoft 信任）（#0、#5）。

⚠️ 為什麼很嚴重？

壞人可以假冒任何網站

Cloudflare：有了這些鑰匙，攻擊者能替任何網域偽造憑證，冒充伺服器去攔截或竄改流量（來源）。

Mozilla 表示已有多人各自算出私鑰，有人已公開（#18）。Cloudflare 表示自家服務尚未發現實際被利用。

🌐 瀏覽器已經處理了

按個開關就封鎖

測試網站說：Firefox、Chrome 自 10/17 起封鎖，Apple 裝置自 10/19、Microsoft 平台自 10/20 起封鎖（來源；網站未註明時區）。瀏覽器用 OneCRL、CRLite、CRLSets 這類快速撤銷機制推送，不必等大改版。Firefox 另於 10/20 發布臨時版本，把封鎖清單內建進去（#16、#17）。

Bugzilla 有使用者回報 Android 版 Firefox 158.0.1 在測試網站檢查全部失敗，Mozilla 表示已知悉（#24）。

🛠️ 非瀏覽器軟體要更新

很多程式不會自動知道

很多程式（App、伺服器、命令列工具、程式套件）不看撤銷資訊，必須更新軟體才會停止信任（測試網站）。Cloudflare 提醒開發者：只更新 SDK 不一定夠，要看底層 HTTP 函式庫、語言執行環境、作業系統；更新後出現憑證錯誤，千萬別關掉驗證（來源）。

Cloudflare 列出要更新的版本，例如 cloudflared 2026.10.2、1.1.1.1 App（Android v6.38.11、iOS v6.31.8）等。

🙋 一般人要做什麼？

三件小事

  1. 把瀏覽器、手機和電腦系統更新到最新。
  2. 更新常用 App；有用 Cloudflare WARP／1.1.1.1 的，更新到上面列的版本。
  3. 看到憑證警告不要按「繼續前往」。

想檢查自己的瀏覽器，可以開 emudhra.we-have-a-problem.com 測試：出現憑證錯誤代表你的瀏覽器沒有信任這些壞憑證，是好事。
