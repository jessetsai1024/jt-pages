  • 11/20 公告；11/23 更新已遭利用 📡GL.iNet 雲端管理平台漏洞遭利用：駭客對部分路由器與 KVM 植入後門，請立即更新韌體 GL.iNet 官方公告：雲端遠端管理服務（GoodCloud）有漏洞，未授權者藉此進入部分 GL.iNet 路由器與 KVM 裝置並安裝惡意程式。官方稱雲端漏洞已修、這條攻擊路徑已封鎖，但已中毒的裝置必須安裝安全韌體才會清除（例如 GL-MT3000／MT6000 需 4.11.1 以上、KVM RM1／RM10 等需 1.10.3 以上、RMQ1 需 1.8.7 以上）。檢查方式：在處理程序中尋找「crond -i /tmp/.log」。BleepingComputer 分析惡意腳本，發現會下載 gl-helper 等程式、開反向 shell 並設定開機常駐；若 KVM 中毒，連接的電腦也應檢查。受害數量與入侵手法官方未公布。 🔗 GL.iNet 官方安全公告（另見 BleepingComputer 分析）↗
  • 11/22 發布後續 🩻後續：遭 AI 代理找到並利用的 MONAI Label 零時差，正式修正版 0.8.6 已發布（CVE-2026-133968） 延續先前 Amazon 揭露的 Cairn 事件：MONAI Label 官方 11/22 上午（台灣時間）發布 0.8.6 安全版本，修正 datastore 上傳端點的路徑穿越漏洞 CVE-2026-133968（GHSA-qc22-rmgc-vg94，嚴重），攻擊者可把檔案寫到伺服器任意位置，進而執行程式碼；另一併修正 session 上傳解壓縮的路徑穿越。0.8.5 以下全部受影響，且預設不需登入。官方建議所有部署立即升級（pip install -U monailabel==0.8.6），曾暴露在不受信任網路的伺服器要先檢查有無異常檔案再上線。 🔗 MONAI Label 官方 GitHub 發布說明（另見 GitHub 安全公告）↗
  • 11/22重大漏洞 🖨️Ghostscript「Upload2Shell」漏洞：上傳一張惡意圖片或 PDF 就可能在伺服器上執行指令，WordPress 外掛、Roundcube 都能觸發 資安公司 pwn.ai 公開 CVE-2026-125396（8.5 分）細節：Ghostscript 載入字型時的 use-after-free 可關閉 -dSAFER 沙箱。ImageMagick、Pillow、libvips 等常見函式庫會把偽裝成 .png／.jpg／.pdf 的 PostScript 內容交給 Ghostscript 處理，因此縮圖、裁切、列印、預覽都可能觸發。示範中約 10 個應用程式成功執行指令，其中 Debian 13 匿名列印、Roundcube 開信、WordPress 外掛 Forminator 與 Essential Addons for Elementor 的公開上傳表單都不需登入。Artifex 已在 9/8 的 10.08.0 修正，目前未見實際攻擊；但部分 Linux 發行版仍未更新，容器或程式自帶的舊版 Ghostscript 也要另外更新。 🔗 The Hacker News（另見 pwn.ai 研究、oss-security 郵件清單）↗

  • 11/22卡資外洩 💳軟體結帳平台 Cleverbridge 遭駭：卡號、到期日連同 CVV 安全碼都被複製 Cleverbridge 替許多軟體與 SaaS 公司處理線上結帳與訂閱（官網客戶名單包括 Red Hat、SUSE、Tenable、Veeam、Jamf、Sony、Parallels，但未說明哪些品牌的顧客受影響）。官方說明 11/4 偵測到未授權活動，系統當天恢復，但調查發現第三方複製了平台上儲存的付款卡資料；11/20 起通知受影響者。BleepingComputer 取得的通知信顯示外洩內容包括卡號、到期日與 CVV/CVC，姓名與帳單地址則未外洩。官方稱不是勒索軟體，受影響人數與入侵方式未公布。International Cyber Digest 提醒：透過 Cleverbridge 的消費在帳單上會顯示為「CBI*」或「CBA*」加賣家名稱（例如 CBI*MALWAREBYTES），買過國外軟體的人可以查一下帳單。 🔗 BleepingComputer（另見 Cleverbridge 官方事件說明）↗
  • 11/22AI 供應鏈 🧠AI 平台 OpenRouter 下架 3 家推論供應商：研究發現多家 AI 代管業者的使用者提示詞遭竊、外流長達數月 Dragos 研究團隊從 7 月到 11 月在約 200 萬則提示詞裡埋入獨一無二的連結與 AWS 金鑰當誘餌，再觀察有沒有人使用。The Hacker News 報導：3 家 AI 推論供應商遭入侵數月都沒發現（最早從 7 月中開始），竊賊會在數小時內試用偷到的 AWS 金鑰，其中部分請求還標示為「零資料保留」（ZDR）。另有市集賣家開啟紀錄收集請求內容，一家未具名的中國 AI 實驗室也讀取了大量測試連結。OpenRouter 官方 11/22 宣布下架 3 家供應商、從 ZDR 資格移除 125 個端點，並已通知可能受影響的客戶，強調自身系統未遭入侵。被下架的業者名稱未公布。用過第三方 AI API 傳送密碼或金鑰的人，建議更換相關憑證。 🔗 OpenRouter 官方公告（另見 The Hacker News 報導 Dragos 研究）↗
