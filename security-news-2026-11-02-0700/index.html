🛠️重大漏洞與修補1 則

  • 10/30 公告・11/1 報導滿分 10.0・已修補 📦Canonical LXD／MicroCloud 滿分漏洞：拿到公開憑證就能冒充受信任的用戶端 Canonical 的容器與虛擬機管理工具 LXD、叢集工具 MicroCloud 有個 CVSS 10.0 的漏洞 CVE-2026-112816：伺服器檢查用戶端憑證時，把整串憑證都拿去比對信任清單，但連線其實只證明用戶端擁有第一張憑證的私鑰。攻擊者只要拿到某個受信任用戶端的公開憑證、接在自己的憑證後面，就能冒充對方進入叢集和虛擬機，若冒充的是管理權限帳號，甚至能拿到主機 root。前提是能從網路連到 HTTPS API（單機 LXD 預設不開）。漏洞由分支專案 Incus 回報（Incus 7.6.0 已修）。目前沒有遭利用的跡象。有用 snap 安裝的，請執行 snap refresh lxd、snap refresh microcloud，並確認版本真的更新了。 🔗 Canonical 官方安全公告；The Hacker News；Incus GitHub 安全公告↗

💸攻擊與外洩事件2 則

  • 11/1後續・FBI 正式認定 🇰🇵幣安 64 億美元竊案後續：FBI 正式認定是北韓 TraderTraitor 所為，幣安開始恢復提領 先前報過幣安遭竊、區塊鏈分析公司 TRM 指向北韓。新進展是：FBI 聯合美國特勤局、國稅局刑事調查處正式認定，北韓駭客組織 TraderTraitor（又稱 Jade Sleet、UNC4899）偷走約 64.3 億美元虛擬資產，正把贓款主要換成以太幣，準備透過 DeFi 和即時兌換服務洗錢，FBI 也公布了相關錢包地址。其中約 28.5 億美元已被 Tether、Circle 等凍結。這是史上最大的加密貨幣竊案，金額幾乎是 2025 年 Bybit 案（14.6 億美元）的四倍多。幣安 11/1 起分階段恢復提領，存款不受影響。 🔗 FBI 官方公告；The Hacker News、BleepingComputer 也報導↗
  • 10/29 事發・11/1 報導後續・原因查明 🎯Polymarket 被盜後續：元兇是網頁測速工具 DebugBear 的網域被劫持，總共賠付 390 萬美元 先前報過預測市場 Polymarket 第三方監測腳本遭駭。新的調查顯示：被換掉的是 DebugBear 的網頁測速腳本，DebugBear 說它的 DNS 紀錄經由網域註冊商被竄改，攻擊看來只鎖定 Polymarket 一個客戶，自家系統沒發現入侵。惡意程式利用交易者已登入的網頁，直接把持倉轉走，或用很差的價格賣掉後把錢領走；駭客錢包不到一小時收到約 264 萬美元。Polymarket 對 726 個受害錢包賠付約 270 萬美元，加上交易暫停期間受影響的約 5,500 個錢包，總共退還 390 萬美元，不用另外申請。 🔗 The Hacker News（引述 Hudson Rock、Ohey 分析）；Polymarket 官方狀態頁；SecurityWeek 也報導↗

🕵️APT 與供應鏈攻擊1 則

  • 11/1研究報告 🏛️卡巴斯基：新惡意程式 NetamLoader 鎖定亞洲政府專用的 Windows 10 卡巴斯基揭露一條「高度精密」的感染鏈，目標是只有亞洲政府機關使用的客製版 Windows 10。惡意檔案被藏在 Windows 更新的下載資料夾裡，借用端點管理軟體 Patch My PC 的合法元件，透過 .NET 的 AppDomainManager 注入載入加密的惡意程式，並繞過微軟的 AMSI 防毒掃描。研究者懷疑是供應鏈攻擊（先入侵受信任的第三方廠商），但檔案究竟怎麼送進去仍不清楚。目前只發現一個受害者，攻擊者身分不明，也不確定是否有資料被偷。 🔗 卡巴斯基 Securelist 研究報告；The Hacker News 也報導↗
