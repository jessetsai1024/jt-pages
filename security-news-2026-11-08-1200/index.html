  • 11/7資料外洩・南韓金融 🏦未來資產證券遭駭：約 3,800 個客戶帳號與 35,255 名員工資料外洩 南韓最大券商未來資產證券（Mirae Asset Securities）週六說，外部攻擊發生在 11/4 與 11/5：先打手機網頁的電話認證登入服務，隔天再打內部群組軟體 mi-global。外洩的是約 3,800 名客戶的帳號，公司強調沒有一併洩漏戶名或其他客戶個資；另有 35,255 名現職員工、前員工與外包人員的姓名、員工編號、電郵、手機號碼與加密密碼外洩，沒有住民登錄號、護照或駕照。公司發現異常外部 IP 後切斷路徑，並向金融委員會、金融監督院與個人情報保護委員會通報。這是未來資產集團兩週內第四家遭入侵的關係企業（人壽保險 10/26 已公布客戶資料外洩）。韓聯社引述主管機關：自 9/30 起約一個月，已有 37 家金融機構通報 40 起外洩、逾 47 萬筆個資，遭竊資金估計約 10 億韓元（約 74.5 萬美元）。請小心冒充該公司的電話、簡訊與電子郵件。 🔗 韓聯社 Yonhap、Aju Press↗
  • 11/7政治人物・暗網 🇮🇹義大利外長塔亞尼：個人資料被丟上暗網，總理梅洛尼指親俄駭客所為 義大利外交部 11/7 證實，資安單位近日在需透過 Tor 才能進入的暗網區域，發現外長兼副總理安東尼奧·塔亞尼（Antonio Tajani）的個人資料。塔亞尼在 X 上寫道，網路犯罪者「連日來」公布他的個資並繼續蒐集更多資訊，等於把他和家人暴露在新的威脅與恫嚇之下；他說攻擊原因是義大利支持烏克蘭的立場。總理喬治亞·梅洛尼（Giorgia Meloni）對此表示聲援，並把此事歸咎於親俄駭客；莫斯科尚未公開回應，這仍是她的說法、並非獨立證實的歸因。塔亞尼也向同樣收到威脅的羅馬檢察官 Francesco Lo Voi、郵政警察局長 Ivano Gabrielli 與市長 Paolo Tassan-Zanin 表達聲援，並要求輪值 G7 主席國把混合威脅列入 11/9–11/10 巴黎外長會議議程。外洩資料的具體內容尚未公布。 🔗 BBC、義大利外交部公報、美聯社↗

  • 11/7開發工具・密鑰外洩 🔑Claude Code「不要再問」會把密碼和金鑰寫進設定檔，公開 GitHub 已有 1,122 份含密鑰 The Hacker News 11/7 引述 Apiiro：在 Claude Code 選「Yes, and don’t ask again」時，它可能把當時核准的整條指令（含密碼、Token）明文存進專案裡的 .claude/settings.local.json。研究人員在公開 GitHub 找到 103,617 個儲存庫、共 104,185 份這類檔案，其中 1,122 份（約 1.1%）至少含一組密鑰、合計 1,379 組不重複密鑰；若再算上舊版檔案、團隊會刻意提交的 settings.json，以及代理對話紀錄，總數是 1,994 個儲存庫、2,539 組密鑰。公開檔裡超過三分之一可直接開資料庫（含 379 組資料庫密碼），另外有 43 組公開伺服器 SSH、42 組 GitHub／GitLab／npm Token、23 組 AWS 金鑰，分布在 63 個組織。Claude Code 只會把檔案加進「這台電腦」的全域 git excludes，不會寫進專案自己的 .gitignore；在追蹤到的 1,105 個儲存庫裡，有 539 個是 Claude 自己當共同作者把檔案交進去的。一家接獲通知的公司確認金鑰當時仍有效。請先輪換檔案裡出現過的每一組密碼與金鑰，再從 git 歷史清掉檔案、加進專案 .gitignore，並改核准指令樣式（例如 npm run:*）或用環境變數，不要把明文密鑰打進指令。 🔗 The Hacker News（引述 Apiiro）↗
  • 11/7後續・企業用戶通知 📬後續：Anthropic 通知企業用戶，稱 10 月有未具名資安公司未經授權進入內部系統 韓國 Byline Network 11/7 引述 Anthropic 當天寄出的個資通知：公司說 10/8 有第三方資安研究公司在未經授權的情況下自行做安全測試，接觸到部分內部系統資料，Anthropic 在 10/10 發現後切斷對方存取並修補弱點。可能被看到的包括姓名、電郵等聯絡資料；企業 Claude 帳戶還可能包括帳戶 ID、組織 ID、方案等級，以及用量與花費相關指標。對話內容、密碼、信用卡與銀行帳戶稱未受影響。該公司已出具書面確認刪除取得的資料、不會再使用；Anthropic 說目前沒發現資料被改或刪、也沒看到濫用跡象，但無法確認個別使用者的紀錄是否真的被打開過，並已向韓國主管機關通報。請小心冒充 Anthropic、以方案或帳單為由索取密碼、驗證碼或付款資訊的釣魚。這則通知的時序（10/8 發生、10/10 發現）與 10 月底披露、當時被描述成授權測試的 Cathedral 事件相近，但本次通知並未點名該公司，是否為同一事件仍標示未證實。 🔗 Byline Network（引述 Anthropic 通知）、RuntimeWire↗
