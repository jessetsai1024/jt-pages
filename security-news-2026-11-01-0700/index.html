🛠️重大漏洞與修補3 則

  • 10/31攻擊程式已公開 📵Android「SMS of Death」：一則看不見的簡訊就能讓手機斷線、當機 研究者 Mark Blaszczyk 公開了 Android 漏洞 CVE-2026-58882 的攻擊程式：對手機號碼送出一則 8 位元組的特製 WAP Push 資料簡訊，就會讓負責通話和行動網路的系統程式當掉，正在講的電話（包括緊急電話）會被切斷，受害者不用點任何東西，收件匣也看不到這則簡訊。連送約 20 則可能讓手機陷入重開機循環。Google 已在 2026 年 10 月的更新中替 Android 14–17 修好，但 Android 12、13 沒有收到修補。請確認手機已裝 10 月以後的安全更新。 🔗 BleepingComputer（引述研究者報告）；Android Authority 也報導↗
  • 10/26 修補・10/31 報導已修補 💬ChatGPT 分享連結漏洞：打開別人分享的對話，私人聊天紀錄可能被偷看 資安公司 Parameter 發現，攻擊者可以做一段看似普通的 ChatGPT 公開分享對話，裡面藏著一張互動圖表和一個 HTML 預覽，兩個功能湊在一起就能繞過沙箱，讓攻擊程式在打開連結的人已登入的 ChatGPT 裡執行，列出並讀取對方的私人對話。OpenAI 10/18 收到通報，10/26 修好並評為最高等級 P1。研究者說只在自己的帳號間測試，沒有發現實際遭濫用；使用者不需要做任何更新。 🔗 The Hacker News；Parameter 研究報告原文↗
  • 10/31後續・已全數修補 🧱Ivanti VPN 後續：三個漏洞串起來可免登入拿到 root，修補已全部推出 昨天報過 CISA 新列 Ivanti Connect Secure 兩個已遭利用漏洞。新進展是：Volexity 說，一個新發現的攻擊者 UTA0576 把這兩個漏洞和驗證繞過漏洞 CVE-2026-104935 串在一起，免登入就能以 root 執行程式，之後專門偷帳密、找管理員密碼和 BitLocker 復原金鑰。Ivanti 說最新版本已修好整條攻擊鏈的所有漏洞。還沒升級的單位請盡快更新。 🔗 The Hacker News（引述 Volexity、Ivanti）；CISA KEV 目錄↗

💸攻擊與外洩事件3 則

  • 10/30–10/31官方公告・已證實 🔑雲端平台 Northflank 遭入侵，客戶存放的 AI API 金鑰被盜用 雲端應用代管平台 Northflank 10/30 接到 Wiz 警報後發現遭入侵，要所有客戶「假設全部環境變數都已被解密」，立刻到原發行商撤銷並重發所有金鑰和密碼，並檢查 AI 服務的用量和帳單。多名客戶已回報 AI API 金鑰被他人使用。公司尚未說明入侵方式和受影響人數。Wiz 的報告指出，光 10 月就至少有 9 起 AI 開發平台遭駭事件（包括 Railway、Warp、Lightning AI 等），攻擊者專門偷 AI 金鑰來白用或轉賣。 🔗 Northflank 官方狀態頁；BleepingComputer 也報導↗
  • 10/31公司證實 🔍區塊鏈鑑識公司 Chainalysis 遭 AI 代理式攻擊入侵，客戶名單外洩 替各國政府和執法單位追查加密貨幣犯罪的 Chainalysis 證實，本月有外部攻擊者用「攻擊型 AI 代理技術」進到內部系統和工具，取得客戶的使用者 ID、全名、電郵和組織角色。公司說調查內容、登入憑證和工作階段權杖沒有被存取，正在修補漏洞。Chainalysis 沒有說明攻擊者身分或具體手法。 🔗 The Hacker News（引述 Chainalysis 通知）；BleepingComputer 也報導↗
  • 10/30–10/31後續・官方更正 🧩Cursor 惡意 Claude Code 擴充後續：2.1.312 版也中招，Anthropic 系統沒被駭 昨天報過 Cursor 擴充功能市集出現植入 SSH 後門的 Claude Code 擴充。Cursor 更新公告：受影響的是 macOS 和 Windows 上的 2.1.312 和 2.1.313 兩個版本（10/29 太平洋時間約 2:27–13:35 上架）。Anthropic 和微軟都證實 Anthropic 系統沒被入侵，官方 VS Code 市集、Open VSX 和 npm 都沒有惡意版本，攻擊者是利用 Cursor 市集的存取權發布。Cursor 說因惡意程式本身有錯，多數電腦上後門其實連不進來，但仍建議照公告的腳本檢查、移除並更換金鑰。攻擊者如何取得發布權限仍未公布。 🔗 Cursor 官方公告；微軟資安部落格、The Hacker News 也報導↗

  • 10/30官方報告 🌊Cloudflare：第三季擋下 1,820 萬次網路層 DDoS 攻擊，比上季多 38% Cloudflare 季報說，2026 年第三季平均每 0.44 秒就有一次網路層 DDoS 攻擊，主要來自出租攻擊服務；10 分鐘內、1 Gbps 以下的短促攻擊暴增 208%。超過 1 Tbps 的超大型攻擊則因今年 3 月執法單位掃蕩多個殭屍網路而減少 69%。最常被攻擊的國家是美國、中國、印尼、英國和土耳其。 🔗 The Hacker News（引述 Cloudflare 第三季 DDoS 報告）↗
