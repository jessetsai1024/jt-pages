🛠️重大漏洞3 則

  • 10/25已證實・未修補 🔑Tailscale SSH 漏洞報告公開，官方承認正在修 昨天標為「未證實」的 Tailscale SSH 提權漏洞，研究者 Erica Windisch（Cyberdione Labs）已在 10/25 發表完整報告「Tailworm」：在 Tailscale 1.104.2 與自架版 headscale 0.29.5 找到 11 個問題，攻擊者只要先控制網路裡一台被允許連線的裝置，就能透過 SSH 連接埠轉送拿到其他伺服器的 root。Tailscale 工程副總在 Reddit 證實收到報告、也發現問題並在修，但目前還沒有 CVE 或修補版本，官方「不建議所有人都關掉 Tailscale SSH」。有用這功能的話，至少先在存取規則裡關掉轉送；headscale 無法關轉送，SSH 授權應視同給了 root。 🔗 The Hacker News（另見 Tailscale 工程副總 Reddit 回應、X 新聞摘要）↗
  • 10/24已遭利用・已修補 ₿Electrum 比特幣錢包「加手續費」陷阱，已有人被偷 Electrum 4.8.3 以前的版本，惡意伺服器可以吞掉你剛送出的交易，換成一筆付給攻擊者的假交易，收款地址還刻意做成「最後四碼一樣」。如果你看交易卡住就按「加手續費（RBF）」，錢包就會替假交易簽名，把幣送給攻擊者。官方說已有伺服器在實際這樣做，至少一位使用者因此損失。請從官網更新到 4.8.3 並驗證簽章；更新前每次簽名或加手續費都要核對完整地址和金額。 🔗 Electrum 官方 GitHub 安全公告（另見 Bitcoin.com News、pwn.watch）↗
  • 10/25新攻擊手法 🤖下載資料夾裡一個 AGENTS.md，就能操控 AI 寫程式代理 Forever Security 在客戶電腦的「下載」資料夾發現惡意 AGENTS.md 指令檔，讓在那個資料夾工作的 AI 寫程式代理去安裝惡意 npm 套件 function-color。研究者重現了對 OpenAI Codex 的攻擊，也示範讓 Claude Code 洩漏 OAuth token、接管帳號。網頁可以不經確認就把檔案下載進「下載」資料夾，所以這是很實際的入口。研究者說這不是廠商能修的漏洞，而是代理照設計讀了指令；建議別在「下載」這種資料夾裡直接開 AI 代理。 🔗 BleepingComputer（Forever Security 研究報告）↗

💸攻擊事件3 則

  • 10/24已證實 ☁️日本 GMO「お名前.com 桌面雲」遭駭，外匯帳戶被盜刷 GMO Internet 的「お名前.com デスクトップクラウド」（很多人拿來跑 MT4/MT5 外匯交易機器人）10/20 被發現遭植入惡意程式，可能受影響的伺服器達 26,739 台，伺服器內存的交易帳號密碼被偷，已有用戶回報 70 多家券商與外匯商帳戶出現非本人交易。GMO 已關閉全部伺服器、報警，說攻擊者勒索並威脅公開資料，但公司拒付；將發每人 5,000 日圓慰問金並補償不當交易的實際損失。用過這服務的人，請用另一台裝置改交易密碼、切斷所有登入中工作階段並開啟兩步驟驗證。 🔗 GMO Internet 官方第 4 報（另見第 3、5 報、東證公告、X 新聞摘要）↗
  • 10/25已證實 🏦印度交易所 CoinDCX 改口承認損失約 1,600 萬美元 印度最大加密貨幣交易所 CoinDCX 10/25 在官方部落格承認，10/21 有 15.99 百萬 USDT 從舊錢包被轉走。這批錢包在 2025 年 7 月那次 4,400 萬美元駭案後就停用，但仍有用戶把幣存進舊地址，自動歸集程式又故障一段時間，錢就累積在已被攻破的地址上。執行長幾天前還說是「誤報」。公司說損失自行吸收、用戶餘額不受影響；Tether 已凍結一部分。提醒：每次入金前都要確認 App 上顯示的最新地址。 🔗 The Block（另見 CoinDCX 官方部落格、CoinDesk、BusinessLine）↗
  • 10/26後續更新 🐘PHP2Shell 後續：歐洲政府機關被打，台灣也在掃描名單 Palo Alto Networks Unit 42 說，攻擊者利用 PHP2Shell 漏洞進入一個歐洲政府機關，兩小時內就拿到密碼雜湊和多因素驗證密鑰，還打進 AD 嘗試取得網域管理員；指令格式顯示是 AI 代理在自動操作。另外 CYFIRMA 發現疑似與北韓有關的低調掃描，鎖定 216 台未修補主機，地區包含台灣、美日韓等，產業涵蓋政府、金融、機場。還沒更新 PHP 的請立刻處理。 🔗 The Hacker News（Unit 42、CYFIRMA 報告）↗
