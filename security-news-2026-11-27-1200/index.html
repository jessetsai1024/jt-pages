  • 11/26已遭利用 🔥Drupal 再發「極度嚴重」漏洞 CVE-2026-136716：上次 Fail2Install 修補沒補乾淨，已遭攻擊接管網站 延續先前報導的 Drupal 安裝程式漏洞 CVE-2026-132165（Fail2Install，已列入 CISA KEV）：Drupal 官方 11/26 再發公告，指出有些網站處在「不尋常或未完成安裝」的狀態，即使已裝上次修補，仍可能被接管，其中包括正式上線的網站，而且從管理介面看不出來；已遭入侵的網站甚至可能已不在易受攻擊狀態。官方確認這個新漏洞已遭實際利用，凡是修補後仍讓 install.php 能從外部連到的網站都可能已被入侵。修正版為 11.4.14、11.3.23、10.6.23（11.0～11.2 與 10.5 以下已停止支援、無修補）；更新後要執行 update.php，並檢查記錄檔與 user 1 帳號的 Email 是否被改、考慮重設 user 1 密碼。 🔗 The Hacker News（另見 SecurityWeek、Drupal 官方安全公告）↗
  • 11/26零時差 🤖後續：Accenture 證實 Mitel MiCollab 漏洞在官方修補前就遭零時差攻擊，疑有 AI 工具協助 延續昨天報導的 CISA 新增 Mitel MiCollab 4 個已遭利用漏洞：Accenture APEX Labs 表示，攻擊者在 Mitel 11/16 發布公告與修補之前（11/15 23:00 UTC 前）就已在受害單位植入 Web Shell，因此「已修補」的單位也不能假設沒被入侵，應主動檢查。在一個案例中，攻擊者第一次請求後 12 分鐘就執行指令、30 分鐘內拿到 root，32 分鐘內用 MiCollab 儲存的 LDAP 帳密登入網域控制站。Accenture 還觀察到攻擊伺服器在送出繞過驗證請求的同一秒連線兩家商用 AI API，且在沒有操作者流量時仍有穩定的指令流，評估部分入侵由 AI 工具驅動（但不代表是全自動攻擊，也未指認攻擊者）。 🔗 Accenture APEX Labs（另見 SecurityWeek、Mitel 公告 MISA-2026-0012）↗

🎯網攻 / 惡意程式3 則

  • 11/26供應鏈 🐍北韓關聯 PolinRider 行動在 GitHub 專案植入 Python 惡意載入器，用以太坊交易藏指令 資安公司 SafeDep 發現，北韓關聯的 PolinRider 行動把惡意載入器藏在 GitHub 專案的 utils 小套件或 conftest.py（pytest 設定檔）裡，只要 Python 匯入就會讀取某個以太坊錢包最新一筆交易的資料，解碼成 JavaScript 用 Node.js 執行，再從另一個錢包找出指令伺服器位址，最後掃描受害電腦上的 GitHub Desktop、Cursor、VS Code 等開發工具。SafeDep 這次在 260 個帳號的 375 個公開專案找到這個載入器，最早可追溯到 2025 年 2 月；The Hacker News 標題所說「超過 7,600 個專案遭污染」是累計整個行動的數字。目前沒證據顯示透過 PyPI 或 npm 散布。這個行動也用假徵才的「回家作業」、盜用維護者帳號、偷開發者 GitHub 權杖強制推送惡意 commit。開發者下載陌生專案執行前要特別小心。 🔗 The Hacker News（原始研究 SafeDep）↗
  • 11/26惡意程式 📧Remus 竊密程式號稱握有「Gmail 零時差」，研究證實其實是偽裝成 Google 試算表的惡意 Chrome 擴充功能 Remus 竊密程式作者 11/8 起宣傳有 Gmail 零時差漏洞，聲稱受害者改密碼、登出所有工作階段後仍能偷信。GenDigital 與 Invoke RE 分別獨立分析後發現，根本不是 Gmail 漏洞，而是惡意程式偷偷修改 Chrome 設定、開啟開發人員模式，裝上偽裝成「Google Sheets」的擴充功能，利用已登入的 Gmail 工作階段抓取未讀郵件的寄件者、主旨和內文。因為擴充功能留在瀏覽器裡，所以改密碼也沒用，只要使用者重新登入就會繼續偷。建議檢查 Chrome 擴充功能清單，看到不認識的「Google Sheets」要移除。 🔗 BleepingComputer（原始研究 GenDigital、Invoke RE；另見 Hudson Rock）↗
  • 11/26惡意程式 🖼️SYS010 透過 Meta 廣告散布假動態桌布，把瀏覽器「納入企業管理」強制安裝偷信擴充功能 Bitdefender 發現新版 SYS01 竊密程式（代號 SYS010）在 Facebook／Meta 投放數百則廣告，偽裝成 Wallpaper Engine、Lively Wallpaper 等免費動態桌布；桌布真的能用，但安裝時會偷偷把 Chrome、Firefox 註冊到攻擊者控制的「企業瀏覽器管理」，強制安裝「Docs Helper」或「Document Hub」擴充功能。它能讀取並上傳最近的 Gmail 和 Outlook 郵件，還能永久刪除攻擊者指定的郵件（可能用來藏起安全通知與登入驗證碼），主要目標是 Facebook／Meta 商業帳號。可到 chrome://management 和 chrome://policy 檢查瀏覽器是否被不明單位管理。 🔗 BleepingComputer（原始研究 Bitdefender）↗

  • 11/26台灣 🦘走著瞧重訊：子公司袋鼠金融（Roo.Cash）遭「AI 自動化攻擊」，估約一成會員個資外洩、全站暫停 Gogolook 走著瞧（6902）11/26 發布重大訊息：子公司袋鼠金融營運的 Roo.Cash 平台 11/25 遭外部攻擊，部分使用者個資外洩，已暫停受影響系統的兌換與查詢功能並通報主管機關。袋鼠金融另向 ETtoday 說明，駭客以 AI 自動化手法攻擊會員系統的「禮物兌換」功能，初估約一成會員受影響，集中在曾透過平台申辦信用卡、貸款並兌換獎勵的人；11/26 上午 11 點起全站暫停服務。公司表示對財務業務無重大影響，將通知受影響者並加強防詐宣導。用過袋鼠金融的人要小心冒名的貸款、信用卡詐騙電話與簡訊。 🔗 ETtoday（另見公開資訊觀測站重訊／MoneyDJ、iThome、工商時報）↗
  • 11/26台灣 🧾電子發票加值平台 PayNow 遭異常存取，約 500 家商家、281 萬張發票的買家個資外洩；香帥蛋糕等發公告 PayNow（立吉富線上金流，奧丁丁集團）初步調查：攻擊者先入侵發票主機拿到設定與金鑰，再透過大量代理 IP 批次讀取發票資料。11/11 發現對外查詢 API 遭異常存取，11/20 又發現另一個發票查詢頁面遭未授權讀取，兩次都在當天阻斷並通報國稅局。合併去重後約 500 家商家、約 281 萬張不重複發票受影響（開立期間 2019 年至 2026 年 11 月），外洩欄位包括買家姓名、地址、Email、手機、載具與購買明細，不含信用卡號與銀行帳戶。香帥蛋糕、一事製菓已發公告，已有買家收到冒用商店名義的「訂單異常」「重複扣款」詐騙訊息。 🔗 iThome（另見香帥蛋糕官網公告 PayNow 事件說明）↗
  • 11/26台灣 📱刑事局：網銀盜轉逾百起、損失逾 1,742 萬元，元凶是偽冒「短劇」App 的 Android 木馬 刑事局 11/26 公布：9 月至 11/21 已受理逾 100 起網銀盜轉案，涉及 19 家銀行與證券商、3 家電子支付共 22 家機構的客戶，累計損失超過 1,742 萬元，多數受害者用 Android 手機，常在深夜被轉帳且沒收到 OTP 簡訊。鑑識發現歹徒在非官方網站散布偽冒短劇 App 的安裝檔，安裝後顯示假的「Google Play 更新」並要求開 VPN 以避開手機防護，再誘騙開啟「無障礙」權限；之後木馬會在數十秒內自行取得 12 類權限，可遠端操控手機、側錄密碼、讀取刪除簡訊、阻止移除。警方呼籲「三不二查一設定」：不從官方商店以外安裝 App、不連不明 VPN、不替來路不明的 App 開無障礙權限。 🔗 iThome（另見刑事警察局公告）↗
