AI 模型「百貨公司」
Sunra 型 vs OpenRouter 型

2026-10-21 整理。所有說法都附官網連結；找不到官方來源的會標 🟡。本頁不是採購或法律建議。

🏬 聚合平台是什麼？

一把鑰匙，逛遍整間百貨

每家 AI 公司像一間獨立的店，要各自辦會員卡（API key）、各自付錢。聚合平台像百貨公司：你只辦一張卡，就能買很多家店的東西，帳單也只有一張。

代價：中間多了一個人經手你的資料，也多了一個可能壞掉的環節。

🎨 Sunra 型：做圖、影片、音樂的工具箱

Sunra（sunra.ai）

✅ 官網確認：官網說可以讓 agent 做圖片、影片、音樂、3D，再編成簡報、影片和場景；也能用 MCP（從 Claude、ChatGPT、Cursor 呼叫）或 API 使用所有模型（sunra.ai）。

付費方式是月費方案換點數（價格頁），例如年繳 Basic $9／月 1,200 點、Pro $17／月 3,500 點、Creator $63／月 17,000 點；點數不能累積到下個月。

⚠️ 價格說法對不上？

✅ 官網確認：Sunra 在 2026-10-19 23:59（台北時間）於 X 發文：Seedance 2.5 每秒 $0.039 起、GPT Image 2.5 每張 $0.004 起、Nano Banana 2.1 每張 $0.015 起，「Up to 81% below other platforms' API prices」（原文）。

但同一串的主文和官網卻說：每個模型都是「at its maker's own API price, with no markup added」（主文），價格頁也寫「Every model at its maker's API price」（價格頁）。

白話：如果真的是「原廠價、不加價」，那比別家便宜 81% 的意思應該是「別家有加價」，而不是 Sunra 比原廠還便宜。兩句話不一定矛盾，但聽起來像「超便宜」的那句，其實只是「不加價」。

🟡 未能從官網確認：三個「起」價和「81%」我在官網價格頁找不到逐一列出的數字，也沒看到是和哪些平台、哪個規格比較；原廠價目前也無法逐一核對。「起」通常代表最低規格（如最低解析度），實際可能更貴。

同類的平台

  • fal.ai：✅ 官網確認「Generative media platform for developers」，圖片／影片／音訊模型＋無伺服器 GPU。
  • Replicate：✅ 官網確認「Run AI with an API」，可跑、微調、部署自訂模型。
  • WaveSpeedAI：✅ 官網確認媒體生成平台，有圖片、影片生成器與開發者文件。
  • Runware：✅ 官網確認隨選模型 API 和無伺服器／專用算力，主打成本低。
  • Krea：✅ 官網確認網頁上可選多家影片、圖片模型（如 Seedance、Flux、Veo）來生成。
  • Freepik AI：🟡 未能從官網確認（官網擋住我的讀取，未能核對）。

💬 OpenRouter 型：幫文字 AI 找路的導航

OpenRouter

✅ 官網確認：

  • 不加價：「no markup on inference pricing」，但買點數時收手續費（FAQ）。
  • 自動備援：主模型遇到限流、當機、內容審核等錯誤時，會改用你列的備援模型，並以實際使用的模型計價（Model Fallbacks）。
  • 比價／挑供應商：同一模型有多個供應商，價格各不同，可選擇或排序（FAQ）。

同類的平台

  • Vercel AI Gateway：✅ 官網確認跨供應商路由和備援，記錄延遲、用量、成本；「no markup and no platform fee on tokens」（價格）。
  • Together AI、Fireworks AI：🟡 未能從官網確認本頁未逐一核對其產品描述；兩家都有公開推論服務文件。
  • LiteLLM：✅ 官網確認可自己架的 OpenAI 相容 gateway（LiteLLM Proxy）。
  • Portkey：✅ 官網確認AI Gateway、觀測、Guardrails、治理；官網稱已成為「PRISMA AIRS AI Gateway」。
  • Cloudflare AI Gateway：✅ 官網確認快取、限流、花費上限、動態路由、DLP 等。

雲端大廠自己的版本

  • AWS Bedrock
  • Azure AI Foundry
  • Google Vertex AI

適合本來就在用該雲、需要合約與合規的公司。

🧭 怎麼選？

簡單三問

  1. 你要做什麼？圖片／影片／音樂 → Sunra 型；聊天、寫程式、文字 → OpenRouter 型。
  2. 要自己掌控嗎？要 → LiteLLM 自架，或用你公司已有的雲（Bedrock／Foundry／Vertex）。
  3. 錢怎麼算？看清楚是「原廠價＋手續費」、「點數月費」還是「起價」，用自己的實際規格試算。

🚨 要小心：可靠度和隱私

多一個中間人＝多一個風險

平台當機、改價、下架模型，你的服務也跟著受影響。重要服務建議準備備援，或保留直連原廠的能力。

各家怎麼處理你的資料（官方文件原文摘要）

  • Sunra：不出售個資；會把資料給 AI 模型供應商（如 OpenAI、Google、ByteDance、快手）等子處理者；不用你的 prompt 訓練自家模型，並表示「正在爭取」供應商的書面不訓練／不保留承諾；保存到帳號存續期間（隱私政策）。
  • OpenRouter：每個供應商政策不同，官方列出各家保存期限與是否訓練（有的保留 30 天、有的零保留、有的「unknown period」），可在帳號設定排除會訓練的供應商（Provider Logging）。
  • Cloudflare AI Gateway：預設開啟紀錄，可關閉，或只關掉 request／response 內容（Logging）。
  • Together AI：可在 Settings > Profile 設定不保留 prompt 與回應（Privacy）。
  • Fireworks AI：有零資料保留（Zero Data Retention）說明頁（文件）；細節未逐條核對。
  • AWS Bedrock：輸入輸出「not shared with any model providers」，資料存在你用的區域（FAQ）。
  • Azure AI Foundry：資料不提供給 OpenAI 等模型供應商、未經許可不用於訓練；但有濫用監控（Data privacy）。
  • Google Vertex AI：文件說明預設開啟快取，可關閉（Data governance）。
  • Vercel、LiteLLM、Portkey、fal、Replicate 等：🟡 未能從官網確認本頁未查到／未核對其資料保留條款。

價格與政策隨時會變，以各官網最新內容為準。本頁由網頁小工坊整理。
