Herdr 桌面版的 Mod：
冰箱上的小磁鐵 🧲

Herdr 桌面版是一個讓好幾個「AI 寫程式小幫手」（像 Claude Code、Codex）一起上班的電腦程式。今天只講它最好玩的地方：Mod。

🧲 Mod 是什麼？

想像 Herdr 的畫面是一台冰箱。冰箱不用換，你只是在上面貼小磁鐵：一個便條板、一個計時器、一組快捷鍵。

官網的說法是：Mod 是「加在你現有版面上的一小塊」，例如一組按鍵或一個面板。

✅ 已查證
📁

磁鐵收在哪？

每個 Mod 都是一個小資料夾，放在電腦裡的 ~/.config/herdr-app/mods/。就像冰箱旁邊那個專門放磁鐵的小盒子。

同一層還有一份 AGENTS.md，算是家規，寫明 AI 小幫手可以改哪些東西。所以你只要開口，小幫手就會照家規幫你貼磁鐵。

✅ 已查證

🔤 官方範例：Tmux prefix

🔔➡️🚪

就像先按門鈴，再說要找誰：

  • 先按 Ctrl+B，畫面上方會跳出一張小提示卡，靜靜等你按下一個鍵（不會自己消失）
  • 按 c：開新分頁
  • 按 n / p：下一個／上一個分頁
  • 按 1～9、0：直接跳到第幾個分頁
  • 按 % 或 "：把畫面切成左右或上下兩格
  • 按 ?：看全部按鍵；按 Esc：算了不按

官網特別說：這只是貼在現有版面上的一小塊，不是換掉整個視窗。

📋 怎麼裝？三步驟

1️⃣

到網站挑一個

打開 herdr.dev/mods，點進喜歡的 Mod。

2️⃣

按「Copy」複製一行字

Tmux prefix 那行字大概是這樣：

Read ~/.config/herdr-app/AGENTS.md, then add this mod: herdr.dev/mods/herdrdev/tmux-prefix

意思是：「先讀家規，再幫我加這個磁鐵。」

3️⃣

貼給你的 AI 小幫手

在 Herdr 裡把這行貼給小幫手，它就會自己動手貼好，放在你原本的東西旁邊。你不用懂程式。

✅ 已查證
✏️

想要自己的磁鐵？

直接跟小幫手講，例如官網的例子：「每個分頁放個計時器，顯示小幫手忙多久了」，它就去改 mods 裡的檔案，做好了。

“You ask, it edits.”（你開口，它就改。）
✅ 已查證

⚠️ 安全小叮嚀

🕵️‍♀️

官方不審查大家做的 Mod。官網說，是靠你的 AI 小幫手在加之前把每個檔案讀過。社群的預覽圖倒是會先過濾，而且至少等 24 小時才出現。

就像陌生人送你的磁鐵：先翻過來看看背面，再貼上冰箱。來路不明的，別急著裝。

✅ 已查證

🎁 怎麼分享自己做的？

1️⃣

請小幫手寫「食譜」

網站上有一段現成的話可複製，貼給小幫手，它會寫出 RECIPE.md：一份別人的小幫手照著就能做出同樣磁鐵的食譜。

2️⃣

放進一個資料夾

  • Mod 本體（mods/ 裡那一份）
  • RECIPE.md 食譜
  • preview.png 一張截圖
  • 需要的話，一小段按鍵設定 keys.json

注意：不要放 layouts/ 資料夾。一個專案可以裝好幾個 Mod。

3️⃣

放上 GitHub，貼標籤

放到公開的 GitHub 專案，加上標籤 herdr-mod。不用註冊，大約一小時內就會出現在網站的 Community 區。

✅ 已查證

🛋️ Mod 和 Layout 差在哪？

🧲 Mod：貼在現有畫面上的小東西（一組按鍵、一個面板）。分享標籤 herdr-mod。

🛋️ Layout：整個畫面的擺法，像把整間廚房重新排過。分享標籤 herdr-layout。

✅ 標籤已查證 ⚠️ 我的推論

「Layout 比 Mod 大一號」是我自己歸納的說法。官網只說 Mod 是「一小塊」、不是整個視窗，也說 tmux 那種較小的東西算 Mod。

📝 阿嬤重點三句話

  • 🧲 Mod 就是冰箱磁鐵：不換冰箱，只多貼一個小功能。
  • 📋 想裝？複製網站上一行字，貼給 AI 小幫手，它幫你貼好。
  • 🕵️‍♀️ 官方不審查，陌生人的磁鐵先看清楚再貼。
