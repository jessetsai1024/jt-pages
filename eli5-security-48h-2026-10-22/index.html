🐛 漏洞與修補

什麼是漏洞？

漏洞像房子門鎖壞了，小偷可以不用鑰匙進門。「修補」就是換新鎖——但你要自己裝上（更新）才有用。

PHP2Shell：網站最常用的語言破洞

✅ 已查證

兩個漏洞 CVE-2026-109618、109619，CVSS 9.2，不用登入就能遠端執行程式。已修補版本：8.5.12、8.4.27、8.3.36、8.2.35（SecurityWeek）。Hadrian 觀察到大規模攻擊嘗試，Unit 42 估計全球逾 2,260 萬個實例可能曝險（iThome）；數發部說國內約 2.8 萬個網站受影響（iThome）。

GitLab CVE-2026-110264

✅ 已查證

CVSS 10.0：正規表示式整數溢位，未登入就可能在伺服器執行程式。10/21 發布 19.5.1、19.4.3、19.3.6、19.2.9、19.1.9、19.0.10、18.11.13（GitLab）。

Linux ksmbd／SMB Direct

✅ 已查證

趨勢科技 ZDI 誤把多份漏洞報告寄到公開的 LKML。SMB Direct 遠端執行（ZDI-CAN-33549）和 ksmbd 競態條件（ZDI-CAN-33774）都是 CVSS 9.0；主線還沒全部修好，部分修補在測試中（Phoronix）。

eMudhra／emSign 憑證私鑰被破解

✅ 已查證

pip 26.2.2（內含 certifi 2026.10.19）於 10/20 發布（pip）；uv 0.13.4 更新內建根憑證、移除受影響的根，之後的 0.13.5 更進一步拒絕受影響中繼憑證（uv）。白話版：我們的 eMudhra 解說頁。

Chrome 156、Firefox 158.0.1

✅ 已查證

Chrome 156 修補 353 個弱點（6 個重大、61 個高風險）；Firefox 158.0.1 修補 4 個（iThome）。

🏠 回家可以做的事

五個小動作

  1. 瀏覽器（Chrome、Firefox）更新到最新。
  2. 有寫 Python 的：pip install -U pip certifi
  3. Linux 使用者：更新核心；沒用到就停用 ksmbd。
  4. 到路由器廠商網站檢查韌體更新。
  5. 小心冒用商家名義、提到你真實訂單的詐騙信，別點連結。
