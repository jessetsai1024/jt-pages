Omarchy 是什麼？

Omarchy 是 DHH（Ruby on Rails 作者）打造、以 Arch Linux＋Hyprland（Wayland 平鋪視窗）為基礎的「主廚精選」桌面系統，目前版本 4.0.4，用 ISO 安裝，回答五個問題即完成。官網表示它「幾乎什麼都能跑」，最新 Dell XPS、Framework 有核心團隊直接支援。

硬體重點

  • 只支援 x86_64＋UEFI；安裝時需關閉 Secure Boot（官方不支援，社群有 sbctl 自簽指南）。
  • 根目錄為 Btrfs（快照）、開機器為 Limine；RAM 2GB 也能跑，但建議 16GB 以上、SSD 256GB 以上。
  • 顯示：Intel／AMD 內顯回報最少；NVIDIA 由安裝程式依世代自動裝 nvidia-open-dkms，但混合顯卡筆電是問題大宗。
  • Wi-Fi：4.x 改用 NetworkManager；Broadcom（Intel Mac）問題最多，Realtek rtw89、Intel BE200 有睡眠喚醒後斷線、MediaTek mt7925 有冷開機需重試的 issue。Intel AX2xx 是最穩的選擇。
  • 睡眠：預設 s2idle 暫停；NVIDIA、部分 Meteor Lake 面板喚醒凍結較常見。
  • 鏡頭：USB/UVC 鏡頭沒問題；Intel IPU6／IPU7 MIPI 鏡頭是最大地雷（Omarchy 只對特定感測器自動處理）。
  • 指紋：手動啟用，依 libfprint 驅動；Goodix MOC、FocalTech 可用，部分 Validity／Goodix 型號不支援，且可能睡眠後卡住。
  • 音效：新款 Intel 平台用 SOF 韌體；最新的音訊放大器晶片常需等核心更新。

Linux 筆電選購檢查清單

  • ✔ AMD Ryzen 或 Intel Core 內顯，避開 NVIDIA 獨顯（除非必要）
  • ✔ 規格寫明 Intel Wi-Fi（AX211／AX203／BE2xx）最好
  • ✔ 查 Arch Wiki「Laptop/品牌」表格有沒有你的型號
  • ✔ 鏡頭是 USB 型（多數 AMD 機）而非 Intel IPU MIPI
  • ✔ 記憶體可擴充、SSD 可換更好
  • ✔ BIOS 能關 Secure Boot
  • ✔ 保留 Windows 雙開機或先用 Live USB 測試 Wi-Fi、睡眠、鏡頭
