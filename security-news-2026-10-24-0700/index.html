🛠️重大漏洞 / 零時差5 則

  • 10/23遭實際利用 ☁️Nextcloud 內建 Collabora 漏洞遭利用，CISA 列入必修 Nextcloud 的「Collabora Online 內建 CODE 伺服器」外掛有指令注入漏洞 CVE-2026-110447（9.2 分），內建伺服器停止時免登入即可遠端執行程式碼。管理員回報 9 月中就被植入網頁後門、翻找密碼庫與加密貨幣錢包。CISA 10/23 列入已遭利用漏洞清單；請升級到 26.4.303 以上或直接移除外掛（只停用不夠）。 🔗 BleepingComputer（另見 CISA 公告）↗
  • 10/24尚無修補 🐘PHP 又一個遠端執行漏洞，暫無修補 PHP2Shell 緊急修補兩天後，PHP 官方再公布 CVE-2026-115560：只有在特殊設定下（執行時把 session 序列化方式改回 php，且開著上傳進度功能）才會中招，官方評估機率低、不發緊急版，建議先設 session.upload_progress.enabled=0。同時，PHP2Shell 攻擊嘗試已達數百萬次，有人試圖植入 Mirai 殭屍網路，但目前未見成功入侵的確認。 🔗 BleepingComputer（另見 PHP 官方公告）↗
  • 10/23已修補 💎Ruby 修好 GitLab 四個重大 RCE 的根源 Ruby 釋出 4.0.9、3.4.12、3.3.13，修補正規表示式引擎 Onigmo 的三個記憶體錯誤，它們正是 GitLab 近一個月四個重大遠端執行漏洞（其中兩個 10.0 滿分、免登入）的根源。凡是用使用者輸入的字串編譯正規表示式的 Ruby 程式都受影響；自架 GitLab 請更新到 19.5.1 等修補版。 🔗 Ruby 官方公告（另見 The Hacker News）↗
  • 10/23已修補 📶HPE Aruba 無線設備 8 個滿分漏洞 HPE 修補 ArubaOS（AOS-8、AOS-10）共 72 個漏洞，其中 8 個是 10.0 滿分的免驗證遠端執行或驗證繞過，影響企業無線控制器、閘道與 AP。目前未知有實際攻擊，建議盡快更新並把管理介面限制在專用網段。 🔗 BleepingComputer（另見 HPE 公告、加拿大網路安全中心）↗
  • 10/23已修補 🖼️Python 圖片庫 Pillow 重大漏洞 最常用的 Python 圖片庫 Pillow 處理 EPS 圖檔時，會把檔名未經檢查交給 Ghostscript，若攻擊者能控制檔名就可能執行指令（CVE-2026-112900）。影響 2.6.0 到 12.3.0，請升級到 13.0.0 以上。 🔗 GitHub 安全公告（另見 The Hacker News）↗

🐉APT / 國家級攻擊2 則

  • 10/23已證實 🥾APT41 用 BlackX 開機木馬，打穿已更新的 Windows Kaspersky 揭露 BlackX UEFI 開機木馬，今年初鎖定塔吉克、烏茲別克、土庫曼的外交機構，以中等信心歸咎中國 APT41。它利用舊漏洞 Baton Drop 繞過安全開機；受害電腦其實都已裝更新，但微軟的修補還需要管理員手動撤銷舊憑證才會生效，很多單位都沒做。 🔗 Kaspersky Securelist（另見 The Hacker News）↗
  • 10/23已證實 🌾俄國駭客聯手，以網狀網路後門抹除烏克蘭企業資料 ESET 指出，親俄組織 UAC-0099 去年 7 月用魚叉式釣魚入侵一家烏克蘭糧食物流公司，部署新後門 MythicRatatoskr（把指揮伺服器藏在 Yggdrasil 加密網狀網路裡），之後把據點交給俄國軍方駭客 Sandworm，在 9 月透過群組原則大規模抹除資料。 🔗 ESET（另見 The Hacker News）↗
