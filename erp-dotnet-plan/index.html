1. 部署原則

全託管雲端，不自建機房

  • 資料庫用託管 PostgreSQL（AWS RDS、Supabase、Neon），內建自動備份。
  • 程式打包成 Docker 映像，部署到 Google Cloud Run、Azure Container Apps 或 AWS。

前端防護與登入控管

  • 前面放 Cloudflare：自動 HTTPS、擋攻擊（DDoS／WAF）。
  • 內部系統再加 Cloudflare Access，只有公司帳號能登入。

程式碼與自動部署

  • 程式碼放 GitHub 私有 repo，用 GitHub Actions 自動部署。
  • 正式環境（production）與測試環境（staging）分開。
項目建議
機房區域東京或新加坡；若資料必須留在台灣，選 GCP asia-east1（彰化縣）
備份每日備份，而且要實際演練還原
權限與稽核完整角色權限＋操作稽核紀錄（audit log）
先評估現成方案開源 ERP：Odoo 或 ERPNext，夠用就不必從零開發

2. 技術框架（.NET）

層面選擇說明
後端ASP.NET Core Web API（.NET 10 LTS）.NET 10 為長期支援版，支援到 2028-11
資料存取EF Core＋PostgreSQL（Npgsql）；Dapper一般 CRUD 用 EF Core；報表與大量查詢用 Dapper
前端Blazor＋MudBlazor，或 React／VueBlazor 全程 C#；React／Vue 則呼叫 .NET API
登入驗證ASP.NET Core Identity 或 OpenID Connect可用 Google／Microsoft 帳號登入；角色權限＋稽核紀錄
架構模組化單體（Modular Monolith）分成進銷存、訂單、會計等模組；初期不做微服務
排程Hangfire 或 Quartz.NET對帳、報表、通知等定時工作
若公司已使用 Microsoft 365，選 Azure（Entra ID 登入、Azure Container Apps）整合最順。

3. AWS 測試環境估價（東京區）

⚠️ 以下皆為大約牌價，以 AWS 官網為準。月費以 730 小時估算；台幣以 1 USD ≈ NT$32 粗估，未含稅。

方案 A：Lightsail 單機 建議先用

一台機器用 Docker Compose 同時跑 ASP.NET Core＋PostgreSQL。

項目規格月費（約）
Lightsail 主機2GB RAM／2 vCPU／60GB SSD／3TB 流量，含固定 IPUS$12（≈NT$400）

方案 B：EC2＋RDS（接近正式環境）

應用程式與資料庫分開，資料庫由 RDS 託管、自動備份。

省錢提醒

  • 新帳號有 AWS 免費方案（Free Tier）額度可用。
  • 不用時記得關機或刪除，避免持續計費（停機的 EC2 仍收磁碟與 IPv4 費用）。
  • 建議：先用方案 A 測試，正式上線再換方案 B。
