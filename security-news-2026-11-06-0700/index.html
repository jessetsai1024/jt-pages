🛠️重大漏洞與修補3 則

  • 11/5嚴重・緊急修補 🔑OpenSSH 緊急修補：在 Alpine 等 musl 系統上，超長密碼就能登入「沒設密碼」的帳號 OpenSSH 今天釋出 10.6p2，修掉一個被評為嚴重的認證繞過：在用 musl C 函式庫、且未走 PAM 的系統（Alpine 預設、OpenWrt／Buildroot／Yocto 若裝 OpenSSH）上，只要密碼登入開著、機器上至少有一個有密碼的帳號，攻擊者對「密碼欄是 *」的帳號（例如官方雲映像的 alpine、或只用 SSH 金鑰的帳號）送 257–1024 位元組的超長密碼，就能直接登入。原因是 musl 的 crypt() 對過長密碼回傳 *，剛好跟鎖定帳號的 * 對上。Alpine 官方程式和官方雲映像（含可 doas 變 root 的 alpine 帳號）都受影響；Debian／Ubuntu／Fedora 用 glibc 或走 PAM 的不受影響。目前沒有遭利用的報告。OpenSSH 專案建議立刻設 PasswordAuthentication=no 或更新後重啟 sshd。截至發稿尚未有 CVE 編號。 🔗 The Hacker News、BleepingComputer（引述 OpenSSH、Alpine 官方公告）↗
  • 11/5後門・已見野 🖥️駭客用被植入後門的 CWP 網頁伺服器打 Linux 主機，後門極隱密、還和 Ebury 一起出現 奇安信 XLab 揭露名為 CWPdoor 的 Linux 後門：攻擊者用假更新腳本，把 Control Web Panel（舊稱 CentOS Web Panel）的 cwpsrv（1.15.10／1.24.0）換成惡意版。後門平常不動作，要等攻擊者送帶簽章的特殊 HTTP 標頭才執行指令，還會壓掉存取紀錄；近一個月公開網路上暴露的 CWP 實例超過 34 萬台。研究團隊 6 月就抓到感染腳本，9/30 又在 VirusTotal 看到與 Ebury 後門同包、且惡意 cwpsrv 零偵測的樣本，研判已有真實受害者。Ebury 與 CWPdoor 的關係目前未證實。有開 CWP 的請檢查 ngx_http_integrity_helper、可疑 helper 行程，並換成原廠二進位、輪換控制台憑證。 🔗 BleepingComputer（引述奇安信 XLab 研究）↗
  • 11/5請更新 🔧Cisco UCS Central 可遠端執行程式；WatchGuard AuthPoint 出三個嚴重認證漏洞 Cisco 修補 UCS Central 的 CVE-2026-76506（高風險）：已認證攻擊者可遠端執行程式或洩漏資訊。WatchGuard 則修補 AuthPoint Authentication Gateway 三個嚴重認證漏洞（CVE-2026-121639／121638／121640）與一個高風險完整性檢查問題；另外說明自家產品內嵌的 Linux 核心含 CVE-2026-98432，但 Fireware／AP 不受那條 RCE 利用鏈影響，Dimension 仍待修。兩家都說目前沒有遭利用的報告。Cisco 也更新 Brotli「Node2Shell」相關公告，已確認 19 款產品受影響、還在調查更多產品。 🔗 SecurityWeek（引述 Cisco、WatchGuard 公告）↗

  • 11/5釣魚・企業帳號 🎣假冒 OpenAI、SpaceX、Anthropic 活動邀請，一次偷微軟與 Google 企業帳號 Push Security 發現攻擊者用假活動報名頁（例如「ChatGPT 行銷團隊講座送三個月 Pro」、「SpaceX 私人活動送 Grok Heavy」）誘騙員工用公司帳號登入。同一頁同時串兩套釣魚即服務：Kali365 做微軟裝置碼釣魚，VoidProxy 做 Google 中間人反向代理，偷憑證、MFA 回應和工作階段 Cookie；微軟路徑還會再導到 VoidProxy 第二關。連結常經 Google／Zapier 縮網址，頁面先過 Cloudflare CAPTCHA 擋自動化掃描。Push 在 10 月底偵測並封鎖相關造訪；這和稍早 ANY.RUN、Cofense 報過的假 AI 活動釣魚同一套路。看到「要簽到才能領獎」的 AI／航太活動邀請，別輸入裝置碼、別用公司帳號登。 🔗 BleepingComputer（引述 Push Security 報告）↗
  • 11/5勒索軟體・已證實 📚紐約皇后區公共圖書館遭勒索軟體，Wi‑Fi、現場電腦與 App 全停 服務 230 萬居民、66 間分館的 Queens Public Library 證實遭勒索軟體，現場電腦、借還書機、Wi‑Fi、數位媒體服務和手機 App 都無法使用；分館仍照常開門，部分活動受影響，已與執法單位和資安顧問合作。截至 11/5 晚間沒有組織認領。圖書館系統常存大量讀者個資，近年西雅圖、多倫多、英國國家圖書館等都曾被勒索軟體重創。 🔗 The Record（引述皇后區公共圖書館聲明）↗
  • 11/5後續・美方警告 ❄️後續：CISA 與 FBI 警告關鍵基礎設施立刻強化冷藏／冷卻系統防護 繼歐洲超市與法國血液中心冷藏設備遭調高溫度後，美國 CISA、FBI 等單位 11/5 發聯合警示，要求醫療、交通、食品、化工等仰賴遠端溫控的單位立刻檢查：拔掉不必要的網際網路連線、強化驗證、更新韌體、必要遠端存取要加嚴。美方指出攻擊者可能利用未修補或曝網的控制器，把設備打進持續加熱／除霜。今年 8 月美國軍中超市也曾出現類似異常，是否相關目前未證實；歐洲近期攻擊同樣尚無人認領。 🔗 The Record（引述 CISA／FBI 聯合警示）↗
  • 11/5勒索研究・加密被擋 🦠Anubis 勒索軟體用新後門 Lindnor 打美國機構，還一次丟 13 套關閉資安工具 Symantec（Broadcom）揭露 10 月一場針對美國組織的 Anubis（集團代號 Hawkmoth）攻擊：攻擊者在兩台 SQL Server 上裝自製後門 Backdoor.Lindnor（偽裝成 Chrome／VMware 元件、以服務執行），約一小時內丟至少 13 個關閉資安產品的執行檔與 5 個已知有漏洞的驅動（BYOVD），並裝 AnyDesk 與可在安全模式跑的工具。加密程式在執行前被擋下，沒有檔案被加密。Anubis 過去一年約宣称 96 名受害者、逾半在美國。初始入侵方式未確認；Lindnor 也出現在另外兩家無關組織，但那些案件沒有後續勒索活動。 🔗 Symantec／SECURITY.COM 研究報告↗

🕵️威脅情報與 AI 資安3 則

  • 11/5OpenAI 研究・重大 🤖OpenAI 資安 AI 管線 30 小時找出並驗證 948 個 Linux 本機提權漏洞，成本約 120 萬美元 OpenAI 公布用即將推出的資安專用模型做成五階段代理管線：發現、動態重現、可利用性評估、產修補、人工複審。10 月中一次約 30 小時的執行，分析 2,308 個候選、動態重現 1,724 個漏洞，並做出 948 個可讓一般使用者變 root 的本機提權 PoC，另有 291 個資訊洩漏 PoC；API 成本約 121 萬美元（每個 LPE 約 1,279 美元），且至少用到 10 種新的 Linux 利用手法。OpenAI 說在人類專家引導下，AI 產的修補可對齊既有程式風格；短期內「有低權限帳號卻沒打最新修補」對有資源的攻擊者可視同已有 root。英國 NCSC 同日也評估 AI 已讓零時差發現量顯著上升。 🔗 The Hacker News、SecurityWeek（引述 OpenAI 官方研究、NCSC）↗
  • 11/5CERT-In・供應鏈 🇮🇳印度 CERT-In：Crafty Falcon 用 AI 攻擊工具打金融與加密貨幣；山寨 ARTEX 映像藏 root 後門 印度 CERT-In 警告代號 Crafty Falcon 的攻擊者，用 ARTEX、PentAGI、Cairn、CyberStrikeAI 等公開 AI 攻擊工具，自動化整條攻擊鏈，鎖定銀行、金融保險、加密貨幣交易所，常從曝網 API 與長效 Token 下手，先轉 1 盧比測試再大額盜領。原廠已下架 ARTEX，但 GitHub／Docker Hub 出現多個複製品；研究員 Badbyte 發現 tomicdd/artex 等映像在登入處理藏了未認證即可拿到 root shell 的後門（CAPTCHA 欄位魔術字串），11/2–11/4 至少 62 台公開主控台在跑這版（美 26、港 17、中 7），映像下載約 9,000 次。公開網路上 ARTEX 主控台共約 1,645 台。本報先前報過 CrowdStrike 對 ARTEX／Vapor Panda 的觀測，這次是官方預警加上山寨映像後門的新進展。 🔗 The Hacker News（引述 CERT-In、研究員 Badbyte）↗
  • 11/5 披露・9/18 已修已修・披露 🔓Check Point：ChatGPT Lockdown Mode 可被繞過，桌面版甚至可能零點擊偷對話 Check Point 披露 ChatGPT 程式碼區塊 HTML 預覽的沙箱漏洞：透過巢狀 iframe 取得未改過的 popup，就能逃出沙箱、繞過 2026 年 6 月上線、用來擋提示詞注入外洩的 Lockdown Mode，進而偷對話、釣魚或誘導下載惡意程式；桌面版（Electron）甚至可能零點擊外洩。OpenAI 已在 9/18 修補。這也呼應前一週 Parameter Labs 用分享連結接管帳號、以及 Check Point 先前展示的跨帳號隱藏指令通道。重點是：AI 產品的防護往往卡在外圍應用程式實作，不只模型本身。 🔗 The Hacker News（引述 Check Point 研究；OpenAI 已修補）↗
