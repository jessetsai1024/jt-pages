  • 11/11（UTC）遭實際利用 🪱駭客劫持 MSP 的 ScreenConnect 面板，近 300 台客戶電腦被植入蠕蟲 Huntress 11/11 發現攻擊者取得多個雲端 ScreenConnect 管理面板，用「Run Command」功能在 90 分鐘內對至少 288 台端點、48 個組織安裝攻擊者控制的第二個 ScreenConnect 用戶端與 SCKit 工具包。SCKit 會等 IT 技術員連進受感染電腦時，反過來感染技術員電腦、再擴散到他能管理的所有主機。ConnectWise 尚未找到初始入侵途徑，已先停用 5 個可疑第三方外掛（RMM Plus 等）。若你用 MSP 代管電腦，請先別透過 ScreenConnect 連到可疑主機，並重設密碼、強制 MFA。 🔗 Huntress（另見 BleepingComputer、Sophos、ConnectWise 公告）↗
  • 11/11PoC 公開 ⚛️React Server Components／Next.js 免登入 RCE 漏洞，攻擊程式已公開 CVE-2026-126187（CVSS 9.5）影響 react-server-dom-webpack／parcel／turbopack 19.0～19.3.0，以及使用 App Router＋Cache Components 的 Next.js 16.0.0～16.4.0；條件是 use cache 函式回傳多個 typed array 加上攻擊者可控的值，屬少見設定，但一旦符合就能在伺服器上執行程式。修補其實 10/14 就已推出（Next.js 16.4.1、React 19.3.1 等），本週 GitHub 上出現可用 PoC，還沒更新的要立刻更新。 🔗 GitHub 安全公告（另見 The Hacker News、Next.js 官方部落格）↗
  • 11/11嚴重修補 🎥Zoom Workplace for Windows 修補 9.6 分免登入提權漏洞 Zoom 修補 Windows 版 Workplace 兩個漏洞：CVE-2026-108186（CVSS 9.6）與 CVE-2026-108187（8.1），都可讓遠端、未登入的攻擊者提升權限。請更新到 7.1.8 以上；Zoom 未提到遭實際利用。同一波 Asus 也修補路由器韌體 4 個漏洞，最嚴重可用 root 執行指令。 🔗 SecurityWeek（另見 The Hacker News）↗
  • 11/10（美東）嚴重修補 🏢Ivanti 端點管理 9.8 分 SQL 注入可免登入執行程式，Citrix、Fortinet 也大量修補 Ivanti 修補 13 個漏洞，最嚴重是 Endpoint Manager 的 CVE-2026-121653（CVSS 9.8，免登入 SQL 注入可達 RCE，修於 2024 SU8）與 Cloud Services Application 的 CVE-2026-121683（9.4，修於 5.0.8.1）；Citrix 修補 XenServer 6 個漏洞，Fortinet 本月修補近 100 個。各家都表示目前沒有遭利用的證據。 🔗 SecurityWeek↗

  • 11/11公司證實 🚢航運巨頭 Maersk 證實遭入侵，勒索集團 WhiteArmor 開價 500 萬美元 Maersk 11/11 證實，一套來自過去收購、只在局部使用的舊系統遭未授權存取並被取出資料，但稱「目前調查強烈顯示沒有敏感資料外洩」，營運與訂艙不受影響。新興勒索集團 WhiteArmor 宣稱從 LF Logistics 平台偷走約 100GB，包括近 3 萬筆司機資料（其中上萬筆明文密碼）、33 個超級管理員帳號等，要求 30 天內付 500 萬美元比特幣。資料內容是駭客說法，尚未獲獨立證實。 🔗 Maersk 官方公告（另見 BleepingComputer、Security Affairs、丹麥 Ingeniøren）↗
  • 11/10～11/11研究揭露 🧩超過 3.5 萬個 Grok 生成的 App 公開可看，部分含機密與明文密碼 資安公司 Claroc 找到 37,571 個用 Grok 聊天建立、發布在 grok.me 子網域的 App，其中 35,578 個不必登入就能開；約一成含內部資料，包括醫院員工名單、病患加護簡報、員工明文密碼，甚至 24 個 X／SpaceXSI 員工自己的機密 App（公司已下架）。問題在於發布時預設勾選「知道連結的人都能看」，而子網域會出現在可搜尋的被動 DNS 紀錄。用 Grok 做過 App 的人，請把有內部資料的改成「僅限受邀者」或「只有我」。 🔗 The Hacker News（Claroc 研究；X 新聞彙整亦有報導）↗
  • 11/11後續 📝後續：Fireworks AI 入侵波及 Notion，部分 Notion AI 對話紀錄外洩 先前報過的 Fireworks AI 入侵，Notion 證實不到 1% 工作區的 Notion AI 對話紀錄（Insights 功能用的資料）被存取，大多數無法對應到使用者或工作區；Notion 已停用 Insights、切斷與 Fireworks 的連線，11/11 並撤銷在對話中找到的 Notion API 金鑰。受影響的人如果曾在 Notion AI 貼過密碼或金鑰，請立即更換。 🔗 Notion 官方公告（另見 BleepingComputer、The Hacker News、VentureBeat）↗
  • 11/11研究報告 🦊開源 AI 滲透測試工具 AntiFox 被拿去攻擊，偷到 AWS 正式環境密鑰 Arctic Wolf 觀察到架在阿里雲上的 AntiFox（GitHub 開源的 AI 自動化滲透測試平台）介面，與多起真實入侵有關：攻擊者先攻破對外 IIS 網站植入 web shell，或拿到外洩的 AWS 憑證，接著自動列舉數十種 AWS 服務，部分案例成功從 Secrets Manager 讀出正式環境密鑰。這是繼 ARTEX 之後又一個 AI 攻擊工具被濫用的案例。 🔗 The Hacker News（Arctic Wolf Labs 報告；另見 BleepingComputer）↗
  • 11/11後續 🔐後續：eMudhra 再撤銷 8 個中繼憑證機構，微軟 11/16 起移除其根憑證 10 月因腳本錯誤把 8 把 ECDSA 私鑰截成只剩 1 位元組的印度憑證商 eMudhra，承認另外 8 把 RSA 私鑰也曾以明文出現在儀式電腦記憶體中、無法證明合規，已撤銷這 8 個 CA（涉及 195 張憑證，含 2 個程式碼簽章用）。微軟 11/16 起移除其剩餘 10 個根憑證，Apple 11/30 起不再信任 G1 憑證。目前未知有遭濫用的案例。 🔗 The Hacker News（另見 BleepingComputer、Mozilla 錯誤追蹤）↗
  • 11/10（波蘭）政府系統 🇵🇱波蘭政府服務平台 ePUAP 遭網攻，緊急下線 波蘭數位事務部長 Gawkowski 表示，民眾與企業用來遞送公文、辦理行政手續的國家平台 ePUAP 遭網路攻擊，已「偵測並阻止」，平台為預防而下線，數位身分 Trusted Profile 也可能受影響。官方稱系統未被攻破、中央資訊中心基礎設施安全，但未說明攻擊手法、來源，也沒有恢復時間表。 🔗 The Record（引用波蘭官方與 PAP）↗
