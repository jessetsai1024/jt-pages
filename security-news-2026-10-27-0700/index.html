🛠️重大漏洞與修補4 則

  • 10/26已遭利用 🐘CISA 把 PHP2Shell 兩個漏洞列入「已遭利用」清單 美國 CISA 10/26 把 PHP 的 CVE-2026-109618（記憶體破壞）和 CVE-2026-109619 列入已知遭利用漏洞（KEV）目錄，並更新它對 PHP 的緊急修補警告。這兩個就是上週公開的 PHP2Shell 遠端執行程式碼漏洞，影響 PHP 8.2 到 8.5。BleepingComputer 也報導已有攻擊成功利用。有跑 PHP 的伺服器請盡快更新到 10/21 的修補版，並重啟 PHP 工作程序。 🔗 CISA 官方公告（另見 BleepingComputer）↗
  • 10/26後續・已修補 🗜️Brotli 漏洞後續：微軟緊急修補 .NET，PHP 重出 Windows 版 前幾天報過的 Brotli 解壓縮漏洞（CVE-2026-111497）又有兩家跟進。微軟 10/25 發布 .NET 緊急安全更新，說在非預設設定下可被遠端提權。PHP 也重新打包 8.2 到 8.5 的官方 Windows 版（檔名帶 -1，例如 8.5.12-1），因為上週的 Windows 版還內含有漏洞的 Brotli 1.2.0。注意 php -v 的版本號不會變，要看檔名或 SHA-256 確認。 🔗 BleepingComputer（另見 The Hacker News 的 PHP 報導）↗
  • 10/26已修補 🧩Wasmtime 兩個 9.9 分漏洞，惡意 WebAssembly 可逃出沙箱 Bytecode Alliance 公布 WebAssembly 執行環境 Wasmtime 的兩個嚴重漏洞，CVSS 都是 9.9：CVE-2026-115889 影響所有架構，CVE-2026-115893 只影響 ARM64。問題都在它預設的編譯器 Cranelift，攻擊者只要讓系統編譯他控制的模組，就可能逃出沙箱。修補版已在 10/19、10/20 推出，目前沒有攻擊報告。風險最高的是會執行別人程式碼的雲端平台。 🔗 The Hacker News（引述 Bytecode Alliance 官方安全公告）↗
  • 10/23已修補 📱Android 版 Microsoft Authenticator 漏洞：零權限 App 能偷公司帳號權杖 研究公司 Enclave 公開細節：在 Android 上，一個完全不要權限的惡意 App 能假裝自己是 Teams，讓 Microsoft Authenticator 交出公司帳號的登入權杖，取得信箱、檔案和行事曆存取權。微軟已在 9 月修好（CVE-2026-80097，CVSS 8.6），修補版本是 6.2606.4246。用公司帳號登入 Authenticator 的人，請確認 App 已更新。 🔗 Enclave 研究報告（另見微軟 MSRC 公告、CVE 紀錄）↗

💸攻擊與外洩事件10 則

  • 10/26進行中 🐙「Gheist」用偷來的 GitHub 權杖，從私有專案偷密鑰 Wiz 追蹤到一個自動化攻擊：拿偷來的 GitHub 權杖在專案裡建一個 ci-sync- 開頭的新分支，放進會把專案密鑰印到 Actions 紀錄的工作流程，下載紀錄後再刪掉。從 9/15 以來已找到 13,500 多個分支、850 多個被盜帳號，私有專案和 GitHub Enterprise 都中招（公開專案大多被 GitHub 的防護擋下）。只刪分支沒用：專案能讀的每個密鑰都要換，推分支的權杖也要撤銷。 🔗 The Hacker News（Wiz 研究，另見 Dark Reading）↗
  • 10/26已證實 🎓哥本哈根大學遭駭，52.5 萬人個資外洩 丹麥最古老的哥本哈根大學證實，駭客進入一個測試環境，裡面有 52.5 萬人的個資，包括姓名、丹麥身分證號（CPR）、電話和電子郵件；後來又追加 2 萬名師生的 PIN 碼外洩。學校仍在調查範圍，提醒受影響者小心釣魚。 🔗 BleepingComputer（引述哥本哈根大學官方說明）↗
  • 10/26已證實 🇰🇷南韓警方：前滲透測試員用 AI 工具入侵 90 多個單位 首爾警察廳鎖定 7 名嫌犯，主嫌是 32 歲、曾在資安公司做滲透測試的駭客。他從 2025 年 9 月起入侵南韓 90 多個單位（學校、醫院、大企業甚至高爾夫球場），偷走 820 萬筆資料，其中 38 起還勒索每次 3.6 億韓元。警方說他大多用 ARTEX 這套 AI 自動化滲透工具，就是之前報過攻擊 ConnectWise 的同一套。 🔗 BleepingComputer（引述韓聯社、首爾警察廳）↗
  • 10/26進行中 🌐美國主機商 DreamHost 出事，強制重設郵件與 FTP 密碼 DreamHost（服務 40 萬客戶、150 萬個網站）10/23 先是檔案管理介面連線異常，接著影響擴大，公司封鎖所有郵件、FTP/SFTP 使用者登入，必須由帳號擁有者重設密碼後才能用。DreamHost 稱這是預防措施，尚未說明原因。有用 DreamHost 的話，請照官方寄的復原說明改密碼。 🔗 BleepingComputer（引述 DreamHost 官方狀態更新）↗
  • 10/26已證實 ✉️比特幣錢包 Foundation 官方網域被拿去寄 2.3 萬封釣魚信 Passport 硬體錢包製造商 Foundation 說，攻擊者透過自架應用程式的漏洞進入後台、拿到 Cloudflare API 金鑰，用官方網域寄出 2.3 萬多封「緊急召回」假信，信裡有收件人真實姓名、地址和購買紀錄，目的是騙取助記詞。公司已撤銷金鑰、關閉惡意網站，說裝置和資金沒受影響，正在調查個資外洩範圍。助記詞絕對不要輸入任何網站。 🔗 Crypto Times（引述 @FoundationHQ 官方 X 貼文，另見 crypto.news）↗
  • 10/26後續更新 🔐Keystone 後續：裝置驗證金鑰被偷，銷毀 18,835 台錢包 之前報過的 Keystone 官網外洩有了更嚴重的更新：攻擊者還偷走寫死在硬體裡、用來驗證「是不是正品」的 WebAuth 金鑰，可能被拿去做能通過驗證的假錢包。Keystone 將銷毀庫存 18,835 台、改用新金鑰、暫停出貨。10/20 前收到且通過驗證的裝置可照常用；之後收到的要聯絡客服再確認。官方不會要求寄回裝置，說「召回」的都是詐騙。 🔗 CoinMarketCap（引述 Keystone 官方 X 聲明，另見 crypto.news、DeFi Prime）↗
  • 10/26進行中 🛒953 家網路商店被植入會躲掃描的惡意程式，多為 Magento 荷蘭電商資安公司 Sansec 發現，從 2025 年 7 月起有駭客在 953 家網店（大多用 Magento）的頁面區塊裡藏了一小段程式。它會先判斷你是真顧客還是資安掃描器，掃描器什麼都拿不到，所以很難被發現。最新的惡意網域 10/6 才註冊，已出現在 83 家店。 🔗 The Hacker News（Sansec 研究）↗
  • 10/26已證實 🎣Microsoft 365 權杖重放攻擊，79 家機構 97 個帳號淪陷 Huntress 發現 7/14 到 9/22 有一波攻擊用「中間人」假登入頁，同時偷到密碼和多因素驗證碼，再把微軟發的登入權杖拿去重放，不必再過一次驗證。共攻陷 79 家機構的 97 個信箱帳號，還註冊了 48 台假的 Entra 裝置。這說明一般簡訊或 App 驗證碼擋不住這類釣魚，能用通行金鑰（passkey）的就換。 🔗 The Hacker News（Huntress 研究，另見 X 新聞摘要）↗
  • 10/26已證實 📹烏克蘭警告：大華監視器透過雲端功能遭入侵 烏克蘭 CERT-UA 說，駭客利用中國大華（Dahua）攝影機的 Easy4IP 雲端遠端功能入侵攝影機和錄影機，改設定、建立未授權帳號。這功能用序號連雲端，即使有防火牆也能連，而序號規律可猜，駭客能大量猜出。官方沒說受害數量和攻擊者。台灣也有不少大華設備，用不到雲端功能就關掉。 🔗 The Record（引述 CERT-UA 官方警告）↗
  • 10/26後續・部分未證實 🇯🇵GMO 遭駭後續：日本首相召開緊急會議 前天報過的 GMO「お名前.com 桌面雲」遭駭事件持續延燒。據 X 新聞摘要，首相高市早苗 10/26 召集閣員開會討論對策，日本將在下週推出緊急資安方案，GMO 股價重挫約 16%；摘要也提到攻擊者勒索 5,000 萬美元。這些細節目前只見於 X 彙整，尚未找到主流媒體或官方文件核實，請視為「未證實」。 🔗 X 新聞摘要（未證實，待官方或媒體確認）↗
