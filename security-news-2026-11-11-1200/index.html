  • 11/10（美東）零時差 🪟微軟 11 月更新修 1,093 個漏洞，Outlook 零時差已遭利用 微軟 11 月 Patch Tuesday 連續第二個月破千，修補 1,093 個漏洞、其中 63 個嚴重等級，近半是遠端執行程式碼。唯一確認已遭實際利用的是 Outlook 偽冒漏洞 CVE-2026-124194，影響 Microsoft 365 Apps for Enterprise 與各版 Office，CISA 已列入已遭利用清單。微軟今年累計已出超過 5,100 個修補，並歸功 AI 協助大量找出漏洞。 🔗 Krebs on Security（另見 The Record、Dark Reading、CISA KEV）↗
  • 11/10遭實際利用 🚨CISA 新增 6 個已遭利用漏洞：Outlook、Chrome、Barracuda、Cisco BroadWorks 等 CISA 11/10 把 6 個漏洞列入已遭利用清單：微軟 Outlook CVE-2026-124194、Chrome CVE-2026-125350、Barracuda 兩個（CVE-2026-116606 認證繞過、CVE-2026-111560 指令注入，聯邦機關限 11/13 前處理）、Cisco BroadWorks XXE CVE-2026-20320、Openwave Webtop Media Transcoder CVE-2026-111793；其餘期限 11/24。 🔗 CISA KEV 資料（另見 @CISACyber 公告）↗
  • 11/9（美西）零時差 🌐Chrome 今年第 8 個遭利用零時差：XML 元件 use-after-free Google 釋出 Chrome 157.0.8103.50／.51（Windows、macOS）與 .50（Linux），修 9 個漏洞，其中 CVE-2026-125350 是 XML 元件的 use-after-free，Google 表示已知有人在野外利用，細節暫不公開。Edge、Brave 等 Chromium 瀏覽器也請盡快更新。 🔗 The Hacker News（另見 X 新聞彙整、CISA KEV）↗
  • 11/9（美東）後續 📧後續：Barracuda 郵件閘道兩個漏洞已遭利用，可串連拿到 root 上週報過的 Barracuda ESG 漏洞 CVE-2026-116606（CVSS 9.3）與 CVE-2026-111560（8.6），Barracuda 11/9 晚間更新公告，確認「少數組織」已遭利用；條件是攻擊者連得到管理介面。請升級到韌體 9.4.0.029 以上，並把管理介面限制在內部網路。受害數量、攻擊者身分與是否真的拿到 root 都還不清楚。 🔗 The Register（另見 Barracuda 官方公告、BleepingComputer）↗
  • 11/10零時差 📴研究者公開 30 多個 N-able N-central 零時差，雲端服務緊急下線 獨立研究者在 GitHub 公開名為「Able2Shell」的 30 多個 N-central 漏洞與 PoC（含帳密外洩、任意寫檔、XXE、遠端執行，可拿到管理權限與 root），事前未給廠商修補時間。N-able 已把雲端 N-central 下線，並呼籲自架用戶先關機；公司稱尚未看到實際利用，但 watchTowr 與 Defused 表示已在蜜罐看到嘗試攻擊與探測。 🔗 TechCrunch（另見 The Hacker News）↗
  • 11/10遭實際利用 🖥️Xen Orchestra 認證繞過遭利用，可接管整個 XCP-ng 主機 Vates 警告 Xen Orchestra 漏洞 VSA-2026-062（尚無 CVE）已遭實際利用：送出特製 cookie 就能以管理員身分登入，進而在受管主機上以 root 執行程式。已修於 Xen Orchestra 6.9.1／6.10.0 與 xo-server 5.211.2／5.213.1。何時開始遭利用、是否為零時差尚不清楚。 🔗 The Hacker News（引用 Vates 官方公告）↗
  • 11/10嚴重修補 🏢SAP 一次修 4 個滿分 10.0 漏洞，免登入即可攻擊 SAP 11 月修補日修了 4 個 CVSS 10.0 漏洞：NetWeaver 的 ICM（CVE-2026-76964）與 Web Dispatcher（CVE-2026-89126）可遠端執行程式碼，SAML 服務（CVE-2026-120017）在部分單一登入設定下可冒充任何使用者，另有 Gateway 冒充漏洞。Onapsis 指出已停止維護的舊核心也受影響、可能拿不到修補，須升級。目前未提到遭利用。 🔗 The Hacker News（SAP 公告、Onapsis 研究）↗
  • 11/10已修補 🌿Git 漏洞：遞迴 clone 惡意儲存庫就可能被執行程式碼 Git 修補 CVE-2026-111760：超長路徑會被截短成 .git，讓攻擊者把子模組的 .git 換成指向惡意 hook 的連結，使用 --recursive clone 時就會執行攻擊者的程式。請升級到 Git 2.56.1（或 2.50.2～2.55.1 對應版）。GitHub 已修好 github.com，Enterprise Server 修於 3.19.15 等版本；寫稿時 Git for Windows 尚未出修補版。 🔗 The Hacker News（另見 Git 官方公告、GitHub 說明）↗

  • 11/10公司揭露 🤖NEAR AI 推論伺服器遭 SGLang 漏洞攻破，連「機密模式」請求也可能外洩 攻擊者利用開源推論引擎 SGLang 的遠端執行漏洞（尚無 CVE、版本未公布），在 NEAR AI 一台推論伺服器上執行程式，當天在 TEE「機密模式」中處理的請求也可能被看到——公司坦言 TEE 擋不住內部軟體的漏洞。攻擊者再取得約 100 名用戶的 Email、姓名，以及 18 個舊版 AI 代理的聊天紀錄與日誌，2 組客戶 API 金鑰已撤銷。 🔗 The Hacker News（另見 NEAR AI 事件報告、X 新聞彙整）↗
  • 11/10後續 🚂後續：Railway 完整事件報告：最多約 10 萬個工作區變數遭解密 先前報過的 Railway 入侵，官方 11/10 公布完整報告：10/20 攻擊者從建置環境部分逃出隔離、拿到建置憑證，一路橫向移動，最多 1.85%（約 10 萬）個工作區的環境變數被解密，主要目標是 AI 服務金鑰（疑轉賣做模型蒸餾）。BleepingComputer 報導遭盜金鑰造成約 74 萬美元的詐用費用，Railway 表示會協助退款或自行吸收。 🔗 Railway 官方報告（另見 BleepingComputer、StepSecurity）↗
  • 11/10後續 ⛓️後續：Initia 三週內二度遭駭，主鏈再度停擺 10 月才因 MoveVM 漏洞停鏈的 Initia，11/10 14:18（台灣時間）再度暫停 L1。Initia 說明攻擊者 11/9 用外洩的 GCP 金鑰做指令注入，再取得 GitHub、GCP 與 rollup 託管平台 Anvil 的權限，偽造 5 條 rollup 的跨鏈提款；約 327 萬美元被轉走，其中 216 萬卡在停擺的主鏈上，約 60 萬美元 USDC 已流出。各方損失數字略有出入，Initia 承諾全額補回。 🔗 0xCERT（另見 Initia 官方 X、Protos、ChainCatcher）↗
