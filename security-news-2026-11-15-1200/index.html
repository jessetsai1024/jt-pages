🛠️漏洞 / 修補2 則

  • 11/14重大漏洞 🔑Apache Shiro 三個嚴重漏洞：開啟 LDAP 登入快取時「任何密碼都能登入」（CVE-2026-129349，9.1 分） Java 安全框架 Apache Shiro 11/14 發布三則嚴重安全公告。CVE-2026-129349（CVSS 4.0 評 9.1）：DefaultLdapRealm／JndiLdapRealm 若開啟 authenticationCachingEnabled，使用者成功登入一次後，之後用任何密碼都能登入，攻擊者只要知道有效帳號名稱即可冒充；此設定非預設，影響 3.0.0 以前所有版本，3.0.1 修正。另有 LDAP DN 注入 CVE-2026-49268（可繞過驗證或冒充他人，修正於 2.2.1／3.0.0-alpha-2），以及工作階段與 Remember-Me Cookie 預設未加 Secure 屬性的 CVE-2026-43828。官方建議 3.x 升到 3.0.2 以上、2.x 升到 2.2.1 以上一次涵蓋三個問題；目前未見遭利用的報告。 🔗 Apache Shiro 官方公告（另見 oss-security 11/14 郵件）↗
  • 11/13～11/14釣魚警告 🎣微軟警告：駭客借 11/12 Microsoft 365 大當機，寄假「服務健康通知」騙密碼 微軟威脅情報 11/14 表示，觀察到一波利用 11/12 Microsoft 365 服務中斷的釣魚郵件，冒充 M365 服務健康通知，還引用真實的 Exchange Online 事件編號 EX1550543，宣稱當機期間被扣住的郵件 24 小時內會刪除、要收件人點連結「救回」。主旨格式為「Outage – 六碼代號」，寄件網域包括 moments-notice[.]com、planetmaison[.]com、newbooker[.]com，連結經 SendGrid 點擊追蹤轉到 reallifeaccounting[.]com，已打到美國多個產業。微軟定性為帳密釣魚，但尚未證實有帳密遭竊；提醒當機狀態請直接到 M365 系統管理中心確認，信裡引用真的事件編號不代表連結安全。 🔗 Microsoft Threat Intelligence（X 官方帳號；另見 Cybersecuritynews）↗
