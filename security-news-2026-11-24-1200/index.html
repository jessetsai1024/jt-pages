  • 11/23已遭利用 🧩舊版 ASP.NET 防 CSRF 套件 Idunno.AntiCsrf 漏洞遭利用：一個 POST 請求就能接管 IIS 伺服器，且永遠不會有修補 Google Mandiant 警告 CVE-2026-131914（9.3 分）已遭實際利用：這個 ASP.NET WebForms 用的第三方模組（0.9.1.0／0.9.1 Beta）用未簽章的 ObjectStateFormatter 反序列化 CSRF token，攻擊者不需登入，只要送一個帶惡意 gadget 的 POST 就能以 w3wp.exe 身分執行程式。這個開源專案自 2008 年就沒更新，不會有修補。建議改用 System.Web.Helpers.AntiForgery、ViewStateUserKey 加 MAC 驗證的 ViewState，或 ASP.NET Core 的 IAntiforgery；並檢查 Web.config 與 bin 目錄裡有沒有 Idunno.AntiCsrf，有入侵跡象的話要輪替 Web.config 裡的所有金鑰與資料庫密碼。 🔗 The Hacker News（引述 Google Mandiant 警示）↗
  • 11/22～23後續 📧後續：N-able Mail Assure 遭駭調查中發現 SSRF 漏洞 CVE-2026-134624，CISA 11/23 列入已遭利用清單（同批還有 MONAI Label） N-able 在調查 Mail Assure／SpamExperts 雲端遭駭時發現 CVE-2026-134624（CVSS 4.0 9.3）：設定轉送時的 LDAP 同步連線檢查沒有限制目的地，有高權限 API 存取的使用者可讓伺服器連到任意內部主機與連接埠。修正版為 20261121.1943，儀表板與 API 已在 11/21 恢復；N-able 未說這是否就是入侵管道。CISA 11/23 把它和 MONAI Label 路徑穿越 CVE-2026-133968 一起加入 KEV 已遭利用漏洞清單。 🔗 SecurityWeek（另見 The Hacker News、CISA KEV 公告）↗
  • 11/23重大漏洞 📦npm 熱門套件 binary-parser 程式碼注入漏洞（CVE-2026-134814，9.2）：可在 Node.js 裡執行任意 JavaScript binary-parser 2.3.1 以前，length、key、tag、offset 等字串選項沒經驗證就被塞進產生的 JavaScript 程式碼，能控制「解析器定義」的攻擊者可在編譯時執行任意程式。維護者說用可信的解析器定義處理不可信的二進位資料不受影響。已在 2.3.1 修正（維護者 11/11 公告），目前未見實際攻擊；有讓使用者自訂解析格式的應用程式要優先升級。 🔗 The Hacker News（另見 NVD、維護者安全公告）↗
