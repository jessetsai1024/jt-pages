ELI5・像講給五歲小孩聽

有人在敲工廠「小電腦」的門 🚪

美國五個政府單位一起發警告：有壞人在找某種工廠用的小電腦。

這種小電腦叫 PLC。我們先看看它是什麼。

PLC 是什麼？

🧠 機器的「小管家」

想像家裡的電鍋：按下去，它自己知道何時加熱、何時保溫。

PLC 就像一個更大、更聰明的「電鍋腦袋」。

它照著寫好的規則，指揮工廠的機器：何時開、何時關、轉多快。

📍 用在哪裡？

警告裡說，最常被盯上的是：關鍵製造業、能源、自來水與污水、化學、食品與農業、商業設施。

這次講的是西門子（Siemens）S7 系列：S7-200、300、400、1200、1500。

壞人在做什麼？

🔍 1. 在網路上找「沒關的門」

就像小偷沿街找沒鎖的門。

壞人用網路掃描服務（例如 Censys、ZoomEye），找到直接連上網路、或分隔不良的 PLC。

🤖 2. 叫 AI 幫忙寫工具

以前要很懂行才寫得出攻擊程式。

現在壞人用 AI 幫忙寫，門檻和時間都大幅降低。

警告說：這是攻擊能力的「進化」。

🎯 3. 把壞工具裝成「好工具」

他們用公開的工具庫（snap7.dll / python-snap7）加上 AI 寫的 Python 程式。

做出來的東西長得像正常的「監控軟體」，讓防守的人以為沒事。

其實它能透過 S7comm 這個溝通方式，讀寫 PLC 的記憶體、設定和程式。

👀 4. 先看、先卡位

他們對資料區做「讀」和「寫」的動作。

警告研判：這是長期偵察，想摸清環境，為以後搞破壞預先卡位。

「讀」多半是偵察；「寫」可能是為未來的破壞預作準備。

可能出什麼事？

⚠️ 警告列出可能後果：

• 工廠流程被打斷，影響產量和品質、公共服務。

• 安全意外：有人被害到（例如關掉安全保護、緊急停機系統）。

• 設備損壞、長時間停工。

• 機密資料外洩、違反法規、連鎖影響其他系統。

這些是「可能」的後果，警告說要看實際情況。

怎麼保護？（給大人看的）

🧾 清點

把環境裡所有 S7 系列 PLC 都列出來，核對韌體版本。

🔨 更新

盡快裝上重要的安全修補，尤其是連到網路的那些。

🔒 別讓它連上網路

最重要的一招。在防火牆「完全封鎖 TCP 102 埠」，把工控網和辦公網分開。

🔑 設密碼、管權限

所有 S7 控制器都開密碼保護，設定讀寫保護等級，只讓授權的電腦連進去。

👁 監看

裝懂工控的偵測系統，盯 TCP 102 埠的異常連線、沒授權的讀寫、snap7 的使用。

🔧 S7 專屬強化

關掉用不到的網頁伺服器和協定、限制同時連線數、開啟「know-how 保護」等功能。

三句話記住

1️⃣ 壞人正在找「直接連上網路、保護不好」的西門子 S7 工廠小電腦（PLC），用來偵察與卡位。

2️⃣ 他們用 AI 寫攻擊程式，再偽裝成正常的監控工具，降低了攻擊門檻。

3️⃣ 最有效的防守：不要把 PLC 連上網路、封鎖 TCP 102 埠、更新韌體、設密碼、持續監看。

要小心的地方

• 這是政府警告（TLP:CLEAR，可自由分享），不是事後鑑識報告；沒有點名是誰、也沒給受害數量。

• 警告特別說：PLC 被攻擊的範圍「不只西門子」，所有 PLC 的業主都該採取防護。這點比簡報更廣。

• 警告的技術細節寫 snap7.dll / python-snap7，透過 S7comm 協定運作（簡報說的 python-snap7 正確）。

• 偵察用「讀」、卡位用「寫」，警告用「potentially（可能）」等字，屬研判，非百分百確定。

本頁未查證：警告未提供具體被攻擊的數量或日期，文中亦無這些數字。
