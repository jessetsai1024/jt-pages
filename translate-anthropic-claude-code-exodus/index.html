Anthropic IPO 前夕，Claude Code 核心主創為何連走三人？

原文作者 lifcc（@mylifcc）· 2026/11/5（台北時間）

來源

原文作者：lifcc（@mylifcc）

原貼連結：x.com/mylifcc/status/2118116581507023262

本頁為 網頁小工坊 的繁體中文（台灣用語）譯文。譯者註記以〔譯註〕標示。本文為意見與分析，非事實查核。

Anthropic 正在衝刺那斯達克（Nasdaq）上市（股票代碼 ANT），10 月 26 日剛交了 S-1 招股書。結果就在路演敲鐘的前夕，公司最賺錢的王牌產品 Claude Code 在短短 11 天裡連走三名核心主創。

10 月 24 日，負責 CLI 生態和 Skills 機制的工程骨幹 Thariq Shihipar（就是 Cat 留言區排第一那位）與 Claude Code 桌面端創建者 Anthony Morris 同一天官宣離職；緊接著 11 月 3 日，把控整個產品方向的負責人 Cat Wu 也交出了工牌。算上今年早些時候跳槽去死對頭 Cursor 的設計負責人 Jenny Wen，當初把 Claude Code 從內部小腳本做成行業標竿的初代核心班底，幾乎走空了一半。

體面人離職，文案自然寫得滴水不漏。Cat 感謝團隊，Thariq 說「依然深信公司的使命，只是想休息一下再開始新東西」，Anthony 則說「很快會分享我的下一個專案」。

為什麼偏偏選在 IPO 前夕組團下車？把矽谷的公關濾鏡扒掉，背後其實是三筆再現實不過的帳：

【股票選擇權落袋與 IPO 窗口期的財務帳】

Anthropic 在招股書和對外宣傳裡一直拿「過去一年主動離職率僅 1%」當金字招牌。為什麼以前沒人走，偏偏 10 月底 S-1 文件一交就接連走人？

因為對於早期加入的核心功臣來說，S-1 招股書遞交、估值徹底鎖定的那一刻，手裡的股票選擇權（options）就已經成了確定性的巨額財富。趕在正式敲鐘前或靜默期交接完離開，既規避了上市後作為核心高階主管嚴苛的次級市場交易監管與漫長的鎖定期綁住，又能揣著暴漲幾十倍的選擇權身家，趁著自己在一線名聲最響的時候直接去拿創投（VC）的天價支票。留言區裡 React 大神樓城（Cheng Lou）調侃問她「是不是要去休那個 6 個月的假了」，其實就是圈內人心照不宣的「財務自由休假」。

【從 940 人到 5300 人的大廠病】

看一眼人員規模就明白創業味兒是怎麼沒的：2024 年底 Anthropic 只有 940 人，到了 2026 年 9 月底已經暴漲到 5300 人，兩年擴招了將近 6 倍。

兩年前 Cat Wu 和 Boris Cherny 搞 Claude Code 時，那是幾個人在內部倒騰出來的極客玩具，想加什麼功能、怎麼改互動，看一眼社群回饋當晚就能上線。而現在的 Claude Code 是扛著公司上市估值的金牛（cash cow），上面壓著合規、企業級安全稽核、大客戶銷售指標和層層報告線。

對於習慣了「幾個人改變一個行業」的初代產品經理和架構師來說，產品已經從「開荒期」進入了「守成收租期」。與其留在 5000 人的準上市公司裡寫 PPT、開跨部門對齊會，不如把接力棒丟給職業經理人。

【他們自己親手寫出了離職的理由】

最耐人尋味的一層原因，其實就藏在 Cat Wu 告別貼文的那句原話裡：

「兩年前大家還要手動點每一個權限提示，如今預設是信任 Claude 自動核准，由它負責建構新產品。」

不久前 Claude Code 團隊才剛揭露過一個內部數據：現在 Claude Code 自己 90% 的程式碼都是由 Claude 編寫和初步審查的。這群人處在 AI 程式設計的最前線，比全世界任何人都更清楚一件事：既然帶著 Claude 引導幾十個小時就能「一行程式碼都不寫」跑通複雜系統，既然現在連自動審批和 Skills 機制都成熟了，那「3 個人 + 無限 Token」就能在外面幹翻一家傳統軟體公司。

當手裡的武器已經強到可以讓三五個人單挑一個團隊時，誰還願意留在幾千人的大廠裡當一顆螺絲釘？

後續懸念

更有意思的懸念還在後頭：負責 CLI 生態和 Agent 架構的 Thariq、負責桌面端互動的 Anthony、再加上掌管全局產品的 Cat Wu，這三個人在 11 天內前後腳離開，湊齊了一家 AI 新創公司最完美的「產品 + 底層架構 + 客戶端」鐵三角。至於他們到底是各自套現躺平，還是在憋一個直接跟老東家或 Cursor 搶飯碗的新專案，等他們的競業禁止期或休假一過就見分曉了。
