  • 11/17（美國時間）重大漏洞 ☕Java 史詩級漏洞「Java4Shell」（CVE-2026-114938）：Jenkins、Jira、Confluence、Keycloak 恐遭遠端執行程式碼，CISA 要求立即修補 資安公司 Calif 公開 OpenJDK 重大漏洞 Java4Shell（CVE-2026-114938），問題出在 Java 硬體加速的 Base64 解碼功能（只影響支援 AVX-512 VBMI 的 x86-64 處理器），特製的 Base64 資料可造成記憶體損壞，進而洩漏記憶體或遠端執行程式碼。Calif 評 CVSS 4.0 為 9.2，Oracle 則評 8.1。受影響的是 OpenJDK 17.0.6 之後版本及其衍生發行版（Oracle Java SE、Amazon Corretto、Eclipse Temurin、Microsoft OpenJDK、Azul Zulu、Red Hat OpenJDK）。Calif 表示在預設設定下，已能對 Keycloak、Jira、Confluence、JFrog Artifactory、Jenkins、PingFederate 做到免登入遠端執行，但沒有通用攻擊程式，需針對各應用找到送入惡意資料的路徑；研究員用 OpenAI Codex 約一小時就找到漏洞。CISA 11/17 發布警示，呼籲盤點所有 JDK（包含第三方軟體、容器映像內附帶的），優先修補對外系統；Oracle 同日的 11 月例行更新共修補 640 個漏洞（Tenable 統計）。 🔗 BleepingComputer（另見 CISA、The Hacker News、iThome）↗
  • 11/17已遭利用 🎭CISA KEV 新增 Puppet Enterprise 反序列化漏洞 CVE-2026-115731：拿到代理憑證就能控制整個 Puppet 伺服器 CISA 11/17 將 Perforce Puppet Enterprise 的 CVE-2026-115731 列入「已知遭利用漏洞」（KEV）清單，聯邦機構期限 12/1。根據 Puppet 官方更新說明及公開漏洞資料，這是 Puppet Server 處理代理回報資料時的反序列化漏洞，持有任何一張 CA 簽發代理憑證的用戶端，就能在伺服器上執行程式碼；若 CA 開啟自動簽發又沒有嚴格驗證，攻擊者甚至可以自己先申請憑證。修補版本為 Puppet Enterprise 2023.8.13、2025.12.1、2026.0.1（同時修補 CVE-2026-115732），升級後須重啟服務。由於 Puppet 伺服器能推送設定到所有受管主機，建議關閉自動簽發、限制網路存取。 🔗 CISA（另見 Puppet 官方更新說明）↗
  • 11/16～11/17後續 🧯後續：Apache Axis 重大漏洞（CVE-2026-90436）攻擊擴及 Confluence；N-able 一口氣修補 N-central 17 個零時差並永久關閉舊 API 本報 11/13 報過 N-central 漏洞串連攻擊。Rapid7 揭露，已停止支援的 Apache Axis 1.x 遠端執行漏洞 CVE-2026-90436（CVSS 9.8）11/13 起也被用來攻擊啟用「Remote API（XML-RPC & SOAP）」的 Confluence Data Center 9.x 以下版本；Apache 不會再修補 Axis 1.x，Atlassian 已在 Confluence 9.2.28 修補，10.0 起已移除該功能。N-able 則推出 N-central 2026.4 Hotfix 3，修補 CVE-2026-129271 至 CVE-2026-129287 共 17 個漏洞，並永久封鎖舊版 API，使已遭用來挖礦的 4EverAble2Shell 攻擊鏈失效；N-able 提醒所有代理程式與 Probe 也必須升級，否則可能遭冒充。 🔗 iThome（另見 SecurityWeek、The Hacker News）↗
  • 11/17遭利用 🖱️ScreenConnect 漏洞 CVE-2026-84869 新一波攻擊：42 台 MSP 伺服器挨打，技術人員一加入連線就被植入程式 Huntress 報告，自 10/20 起有攻擊者利用 ConnectWise ScreenConnect 已於 9 月修補的 CVE-2026-84869（CVSS 9.9），從 29 個 IP 對 42 台 IT 委外服務商（MSP）的 ScreenConnect 伺服器送出至少 68.8 萬次「訪客推送執行檔」請求，等技術人員加入連線時，讓技術人員電腦在沒有提示下執行惡意批次檔，安裝偽裝成 Windows Update 的 ScreenConnect 用戶端。Huntress 指這波攻擊與先前 SCKit 蠕蟲攻擊不同。由於 MSP 技術人員電腦通常握有所有客戶的管理權限，建議把技術人員端的 ScreenConnect 升級至 26.6.5 以上。 🔗 SecurityWeek（另見 The Hacker News）↗
  • 11/11～11/13 公布（先前未報）遭利用 📹台灣奇偶科技 GeoVision 監控軟體已知漏洞遭利用：13 家組織的錄影主機被裝挖礦程式 國內影像監控業者奇偶科技（GeoVision）11/11 發布資安通告，指攻擊者鎖定暴露在網路上、啟用 WebCam Server 功能的 NVR，利用已知遠端執行漏洞入侵並部署 XMRig 挖礦程式。Huntress 11/13 報告，11/8～11/10 間觀察到涉及 13 家組織的攻擊，攻擊者還用具漏洞的驅動程式（BYOVD）干擾防毒。奇偶要求更新修補 CVE-2026-7372、CVE-2026-42369、CVE-2026-42370（今年 4 月已釋出修補）。家中或公司有 GeoVision 錄影主機者，請勿直接暴露在網路上並盡速更新。 🔗 iThome（另見 Huntress、奇偶科技資安通告）↗
