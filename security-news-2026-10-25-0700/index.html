🛠️重大漏洞4 則

  • 10/24已修補 🗜️Brotli 解壓縮漏洞不只 Node.js，Bun、Python、Envoy 也中 Google 的 Brotli 解壓縮 C 程式庫有記憶體越界寫入漏洞 CVE-2026-111497（Google 評 9.2 分），任何會解開別人送來的 Brotli 壓縮資料的程式都可能被搞當機、洩漏記憶體甚至執行程式碼。Imperva 已在一個未修補的 Node.js 版本上示範執行程式碼；Bun、Python 的 Brotli／brotlicffi 套件、開了 Brotli 解壓的 Envoy 與 Istio 也受影響。Python 只要裝了套件，requests、httpx 等用戶端就會自動解壓，等於不知不覺暴露。目前未見實際攻擊，請把 Node.js、Bun（1.4.4）、Python Brotli（1.2.1）等逐一更新。 🔗 The Hacker News（另見 Node.js 官方安全公告、Red Hat）↗
  • 10/24研究者自救 🍿廢棄的 Popcorn Time 分支讓數百萬台電腦暴露 Popcorn Time 分支 Time4Popcorn 的更新程式用未加密 HTTP 連到已被棄置的網域，而且不檢查簽章就以最高權限執行下載的程式（CVE-2026-30612，9.8 分）。誰搶註網域誰就能控制所有還裝著它的電腦。資安公司 Eye Security 搶下網域後，推送超過 200 萬次「只會關掉更新程式」的更新，再把網域交給 Shadowserver 管理；但仍有部分網域在外人手上，還裝著這套軟體的人請直接移除。 🔗 BleepingComputer（另見 The Hacker News、Eye Security 報告）↗
  • 10/24後續更新 📋CISA 把 Arista VeloCloud 零時差列入必修，期限 10/26 前天報過的 Arista VeloCloud Orchestrator 零時差漏洞 CVE-2026-114625，CISA 已和 Collabora 漏洞一起列入「已遭利用漏洞清單」，要求美國聯邦機關 10/26 前修好。這是該產品今年 7 月以來第三個被實際利用的漏洞，有用的單位請優先處理。 🔗 The Hacker News（另見 CISA 公告）↗
  • 10/24未證實 🔑【未證實】研究者稱 Tailscale SSH 有新的提權漏洞 研究者 Erica Windisch 在 X 上表示發現 Tailscale SSH 功能的提權漏洞，先公布雜湊值、完整報告尚未發表，並呼籲先關閉 Tailscale SSH（sudo tailscale set --ssh=false）。截至整理時 Tailscale 官方安全公告尚未出現對應的新公告，細節無法證實；有開這個功能的話，暫時關閉是低成本的預防。 🔗 X 新聞摘要（單一來源，未獲官方證實）↗

📦供應鏈攻擊1 則

  • 10/24後續更新 🗝️LiteLLM 被植入木馬的原因：5 月外洩的金鑰沒撤銷 前天報過的 LiteLLM 1.107.0 惡意版本，官方公布完整攻擊鏈：5 月時一把 Agent Platform 主金鑰被誤推到公開 GitHub，雖然很快刪除但沒有撤銷。攻擊者 10/10 用它進入平台，拿到一個權限過大、屬於 GitHub 組織擁有者的 token，再偷工程師的 token，趁發版審核暫時放寬時把發版流程指向仿冒的 repo，10/21 發出竊密木馬版。教訓很實際：外洩的金鑰一定要撤銷，token 權限要縮小。 🔗 LiteLLM 官方說明（另見 The Hacker News、Microsoft、Socket）↗

💸攻擊事件1 則

  • 10/24已證實 ⛓️Initia 區塊鏈遭駭約 270 萬美元，整條鏈暫停 Initia 的 MoveVM 腳本快取有漏洞，攻擊者繞過檢查、憑空灌出 WETH、AUSD、USDC 餘額，42 分鐘內經跨鏈橋換走約 270 萬美元（現為 1,135 顆 ETH），Initia 隨即暫停 L1 與所有 rollup。官方說原生 INIT 不受影響，修補與稽核預計數天內完成；在官方確認前別往 Initia 跨鏈轉帳。 🔗 The Block（另見 0xCERT、Bitquery 鏈上分析）↗

🔓資料外洩1 則

  • 10/24已證實 👛Keystone 硬體錢包官網遭駭，買家地址外洩 Keystone 公告：10/20 發現官網遭未授權存取，與 Shopify 核對 API 紀錄後，10/23 確認買家姓名、聯絡方式、收件地址和訂單內容被取走；付款資料、助記詞、私鑰和密碼不在其中。最大風險是冒名詐騙：已有買家接到假冒來電。任何人打來說要退款、換新機或要你輸入助記詞，都是詐騙。 🔗 Crypto Briefing（另見 Keystone 官方 X、Bitcoin.com、TokenPost）↗

🏛️政策 / 執法1 則

  • 10/23已證實 🚫美國 FCC 首度依晶片禁售：華為海思監控晶片產品 FCC 依 10/13 生效的新規定，首次以「內含黑名單廠商的晶片」為由，禁止一款行車記錄器和一款無線影像傳輸器在美國上市；兩者都用華為子公司海思的監控晶片（具人臉偵測）。等於堵住「換牌子、換外殼就能賣」的漏洞，之後可能有更多產品被擋。 🔗 The Record（另見 Reuters、Tom's Hardware、FCC）↗
