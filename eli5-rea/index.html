🔍 REA：把任何軟體「拆開來看」

Reverse Engineer Anything，給 AI 助手用的放大鏡工具箱

是什麼怎麼運作能看什麼安裝爆紅限制與法律來源

1. 它是什麼？

App 像做好的蛋糕，沒附食譜。

REA 讓 AI 助手（Claude Code、Codex、Cursor、Grok Build…）沒有原始碼也能研究它怎麼做的。免費開源，MIT 授權。

2. 怎麼運作？

REA 自己不會思考，只是「遞工具的人」。

它在你電腦上叫 Ghidra、Hopper、IDA、JADX 等工具，帶回虛擬碼、組合語言、引用位置，附上證據和限制。由 AI 助手解釋或重做功能。

3. 能看什麼？

程式、App、網站、韌體都能看。

原生程式要裝 Ghidra/Hopper/IDA；.NET 只做靜態分析（不執行）；APK 用 JADX。還有更多：WASM、封包、資料庫…

4. 怎麼安裝？

先有 Node.js 22.19 以上，再打一行：

npx rea-agents setup

只要指令列：npm install --global rea-agents，更新用 rea update。

README 寫的 Node 版本：22.x（≥22.19）、24.x（≥24.11）或 26+。

5. 一週爆紅

從不到 1 萬顆星，衝到二十幾萬顆。

Decrypt：10/6 不到 1 萬、10/12 超過 10 萬。System Design Academy：10/12 有 109,288。README 現在寫「200,000 星」；GitHub API 10/14 實測 227,693。

6. 限制與法律提醒

它像別人畫的地圖：畫出來的路可信，空白處要自己走。

  • 不保證還原原本的原始碼。實測：30 處位置全對，但 8 處「回傳訊息」一處都沒記到。
  • 只分析自己的或有授權的軟體。很多授權條款禁止逆向，各國法律也不同；REA 不支援破解 DRM、作弊、盜版。
  • Decrypt 標題提到 GTA V 上 iPhone、免費 Photoshop。那是媒體報導，而且文中說 ArtCraft 不是用 REA 做的。這類用法有法律和道德風險，已有遊戲公司下架影片、寄存證信函。
  • 小心假冒的山寨 repo（例如 10/10 出現的 rea-tools/rea）。只從 github.com/morluto/rea、rea.tools 或 npm 的 rea-agents 安裝。
  • 分析在你電腦上跑，但結果會送到 AI 助手的模型供應商。
