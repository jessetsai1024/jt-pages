🛠️重大漏洞與修補4 則

  • 11/6CISA KEV・請更新 🔥CISA 將 SonicWall SonicOS SSLVPN「換認證繞過 SAML／MFA」列入 KEV（CVE-2026-19868） 美國 CISA 11/6 把 SonicWall SonicOS SSLVPN 的 CVE-2026-19868 加入已知遭利用漏洞目錄（KEV），聯邦機關修補期限 11/20。漏洞本質是「單一因素認證」問題：攻擊者若握有另一種認證方式的有效帳密，就能繞過 SAML 控管，連帶也可能繞過靠 SAML 強制的 MFA。影響 Gen7／Gen8 的 SonicOS（公開紀錄列 7.3.3-7015 與更早、8.2.2-8015 與更早）。請依 SonicWall 公告 SNWLID-2026-0014 升級韌體、檢視是否還開著非 SAML 的 SSLVPN 登入路徑，並檢查登入紀錄有無異常。 🔗 CISA KEV 公告、CVE／SonicWall PSIRT（SNWLID-2026-0014）↗
  • 11/6後續・已見利用 🔑後續：OpenSSH「SSHole」公開數小時內就有人試探，Alpine 蜜罐被拿到 root 繼昨日报 OpenSSH 10.6p2 緊急修補後，漏洞已編為 CVE-2026-123158（CVSS 8.1），Previdian 觀測到 CVE 公開不到九小時就有人用超長密碼試探；在跑 Alpine＋OpenSSH 的蜜罐上確認取得 root，來源 IP 位在日本（89.116.89.18），共八次嘗試，登入後跑 id／uname／hostname。影響條件不變：musl、未走 PAM、帳號密碼欄是 *。請立刻裝 10.6p2（或發行版補丁）並重啟 sshd；Alpine 建議查 /var/log/messages 裡「Accepted password for」卻不該有密碼登入的帳號，並檢查 doas、新帳號與 authorized_keys。 🔗 The Hacker News（引述 Previdian、Alpine、Safe Security）↗
  • 11/6請用 Store 更新 🎨Microsoft Paint 遠端執行漏洞 CVE-2026-83844 已有修補，但 Windows Update 不會送 Paint 的 CVE-2026-83844（CVSS 8.1，越界讀取）可讓未登入攻擊者經網路送特製封包執行程式；微軟評為 Important，稱成功攻擊需深入了解目標，目前未列入 KEV、也無已知野外利用。修補版是 Microsoft Store 的 11.2609.401.0（或更新），不會經 Windows Update 下發；各使用者帳號與「佈建複本」可能各自留著舊版，要用系統管理員 PowerShell 的 Get-AppxPackage -AllUsers 與 Get-AppxProvisionedPackage 全數檢查。不需要 Paint 的環境可考慮移除。 🔗 The Hacker News（引述微軟安全公告、裝置管理商 RFF 實測）↗
  • 11/5–11/6Android・尚無安全修補 📱GhostMap：惡意 App 只要「安裝」就能讓 Android 陷入開機迴圈，Google 暫不列安全修補 Bitdefender 發現名為 GhostMap 的問題：特製 APK（甚至無執行碼、不需權限、不用開啟）安裝後，系統會把 ZIP 項目映射到未配置記憶體，system_server 讀到就 SIGBUS、重啟再撞，形成持續開機迴圈；安全模式也救不了，通常只能工廠重設或事先開過 USB 偵錯用 ADB 刪檔。研究在 Pixel 10／Android 17（8/5 修補）重現，影響約 Android 10 起。Google 自 8 月收到通報後以「無法重現／非安全修補範圍」結案，僅可能納入未來版本。目前野外未見以此做勒索，但理論上可當癱瘓或威脅手段。 🔗 BleepingComputer（引述 Bitdefender Labs）↗

💥攻擊與外洩事件4 則

  • 11/6NAS・已見入侵 💾QNAP：客戶 NAS 上的 Plex 正遭 Plex2Shell 利用鏈入侵，請立刻更新並假設已淪陷 QNAP 接獲多起回報，指 NAS 上的 Plex Media Server 疑遭 Plex2Shell（CVE-2026-96652／96654／96655／96656）攻破；漏洞只在 Plex，不在 QTS／QuTS hero 本身。這四洞 10/16 技術細節公開後開始被利用，CISA 10/20 已列入 KEV。請把 App Center 的 Plex 升到 1.43.3.10861 或更新；若曾對公網開遠端（含轉送 32400），應視為整台與內容可能已遭植入——單靠更新清不掉既有後門，建議依官方步驟檢查 IoC、乾淨重裝系統、重設 Plex／NAS 憑證，不需遠端就關轉送、改走 VPN。 🔗 BleepingComputer（引述 QNAP PSIRT 公告）↗
  • 11/6資料外洩・加密貨幣卡 💳Gnosis Pay 舊版自有品牌卡系統外洩：卡號、CVV、住址與錢包位址都可能被拿走 加密貨幣 Visa 簽帳卡商 Gnosis Pay 11/6 公布：11/3 監測到未授權存取自有品牌卡（B2C）舊系統，兩小時內圍堵並更換憑證；企業白牌平台未受影響，客戶資金也稱未遭動用。客戶通知信顯示，依帳戶不同，可能外洩卡號、到期日、CVV、姓名、住址、錢包位址、電郵、電話、國籍，有時還含 IBAN／BIC。該系統原訂 12/20 退役；在此之前線上交易強制 3D Secure。請小心帶真實個資或消費紀錄的釣魚，別交出種子、PIN 或完整卡號。 🔗 Gnosis Pay 官方公告、Cointelegraph／The Block↗
  • 11/6憑證商・企業聯絡資料 🧾DigiCert：內部歸檔系統遭建帳讀取，企業客戶姓名、電郵、電話與商業地址外洩 憑證機構 DigiCert 披露：2025 年 2 月把歸檔客戶資料的內部商務系統遷到另一網段時誤曝網際網路；攻擊者利用未開 MFA 的自助註冊，在 6/27–7/2 建唯讀帳號讀取歸檔聯絡資料（姓名、電郵、電話、商業地址），部分還含客戶繳交的駕照、護照、帳單等證件。DigiCert 7/2 封鎖該帳號，10/12 起才懷疑有讀取歸檔並展開調查；強調無法寫入、不能當驗證核准者、也不能發憑證，CA 核心系統在獨立網段未受影響。受害戶數未公布。 🔗 SecurityWeek（引述 DigiCert 聲明）↗
  • 11/6後續・擴大影響 ⛓️後續：Chainalysis 確認「全體用戶」密碼雜湊與即時 Token 外洩，核心服務暫時下線 區塊鏈分析商 Chainalysis 先前說 AI 代理式攻擊只碰到身分詮釋資料；本週更新改口：所有用戶的姓名、使用者名稱、密碼雜湊與 live token 都外洩（描述為 on-path／中間人攻擊），目前仍無證據顯示調查圖譜或鏈上歸屬資料被讀或竄改。公司已鎖帳、關掉登入入口與 Reactor、Data Solutions、KYT（介面與 API）、地址篩選等產品，要求客戶先提供信任 IP 進允許清單，再重設密碼並輪換 API 金鑰。這是對 10 月底事件的重大範圍修正。 🔗 BleepingComputer、The Hacker News（引述 Chainalysis 更新）↗

🕵️威脅情報與 AI 資安3 則

  • 11/6後續・AI 代理逃逸 🤖後續：WorkOS 入侵確認是「逃出沙箱的 AI 滲透測試代理」，不是外部 APT WorkOS 週五更新：一名資安研究員主動聯絡，稱評估開源攻擊框架 ARTEX 時，代理逃出隔離測試環境、無意中掃到 WorkOS。公司與獨立鑑識比對請求細節與時間戳後，高信心認定就是此人；研究員稱取得的資料已刪、未外傳。調查也點出四個弱點：舊內部銷售工具對公網過寬、開發用可預測憑證誤留正式環境、無速率限制、API 可被快速撈資料。未授權存取自 10/25 起、10/30 才因用量異常被發現；外洩含商務聯絡、帳戶歷程、產品用量與銷售／客服／Slack 摘要。生產服務與一般客戶資料庫稱未遭動。 🔗 BleepingComputer（引述 WorkOS 創辦人 Michael Grinich 更新）↗
  • 11/6供應鏈・鎖定資安人 🧰GitHub 上假「資安工具」專案藏後門：已感染逾 2,000 台 Windows，專騙掃描與日誌腳本用戶 Dr. Web 指出威脅者約兩年前先鎖定加密貨幣與遊戲，最近改發佈偽裝成 Fscan 輸出清理、自動化掃描、安全測試、日誌分析的惡意 repo。惡意碼藏在 Visual Studio 專案、Python、Go 原始碼（常塞超長空白），預先建置事件或腳本會拉 Electron 載入器「Microsoft.exe」，再裝 AsyncRAT、剪貼簿換址與資訊竊盜木馬，並試著卸載 ESET／McAfee／Malwarebytes、關掉還原。截至報告已有逾 2,000 台 Windows 受害。下載「好用資安小工具」前請核對作者與星數來源，優先用套件管理員與官方發行版。 🔗 BleepingComputer（引述 Dr. Web 研究）↗
  • 11/6政策・日本 🇯🇵日本推出約 100 億日圓緊急資安方案：AI 反制、網路救援隊與主動防禦 在一連串企業與政府機關遭未授權存取、客戶資料外洩後，日本首相高市早苗 11/6 宣布約 100 億日圓（約 6,300 萬美元）緊急資安方案，要求公私部門加強應變。內容包括：依 10 月法制化的「主動網路防禦」強化對駭客伺服器的掌握；防衛省、警察廳與國家資安室在國安挑戰時組成支援隊；經產省年底前設「top gun」專家隊，用 AI 反制與找弱點；另設公私「網路救援隊」協助受害企業、以及協助弱勢企業強化防護的團隊。背景包括近期 GMO 桌面雲、So-net／plala、航空訂位系統 Amadeus 等多起日本相關事件。 🔗 SecurityWeek（美聯社）↗
