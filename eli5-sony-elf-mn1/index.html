👀 不用戴眼鏡的 3D 小螢幕
Sony ELF-MN1，講給阿嬤聽

編譯時間：2026-10-28 19:04（台北時間）

🌟 三句話就懂

  1. 它是一塊手機大小（6 吋）的小螢幕，不用戴眼鏡，就能看到卡通人物「站」在桌上。
  2. 秘密是螢幕上一層超小的放大鏡條紋，讓左眼、右眼看到不一樣的畫面，大腦自己拼成立體。
  3. 上面的小眼睛會一直找你的眼睛在哪，所以一次只能給一個人看。

🧸 1. 它是什麼？

像一個會變魔術的小相框

大小跟手機差不多，重量 300 克，大約是一顆大蘋果加一顆橘子那麼重。插上手機或電腦，畫面裡的小人好像真的站在你桌上。

  • 6 吋、1080×2160、403ppi、亮度 470 nits 已查證
  • 本體 300 克（含支架等配件 350 克） 已查證
  • 日本 2026/12/11 開賣；Sony Store 售價 ¥53,900（官方「オープン価格」，市場推估約 ¥54,000） 已查證
  • 約新台幣 11,000 元（依匯率粗估） 未查證
  • 台灣尚未販售：查不到台灣上市消息 未查證

可以接什麼？

  • Windows 11 電腦 已查證
  • 顯示卡：官方建議 RTX 2070 SUPER 以上（或 Radeon RX 5700 XT），不是 RTX 2060 有出入
  • iPhone 15／16／17／18 標準版與 Pro 已查證
  • 還支援 Android 手機（Xperia、Galaxy、Pixel 部分機型），原說法漏了 有出入
  • Mac：官方規格沒列出 Mac 未查證（官方未明說不支援）
  • 要用一條支援 DisplayPort Alt Mode 的 USB-C 線連接（有附），變壓器另購 已查證

🔍 2. 為什麼不用眼鏡就有 3D？

左眼、右眼各看一張圖

螢幕的小點點排成一條粉紅、一條藍，交錯排好。上面蓋著一層像波浪形小放大鏡的膜，把粉紅條送到左眼、藍條送到右眼。兩眼看到有點不同的圖，大腦就把它「拼」成有深度的東西。

官方叫它「微光學透鏡方式液晶面板」；說是兩個視點（2視点方式） 已查證

原理是「柱狀透鏡（lenticular）」：這是我們依官方描述的推論 未查證（官方用詞不同）

🎴 就像小時候的「會變圖卡片」

文具店那種斜斜看會換圖的卡片，表面也是一條條小透鏡。差別是：卡片要你自己歪頭，這台會跟著你的頭換畫面。另一個比方是任天堂 3DS 的裸眼 3D，概念類似（不過 3DS 用的是另一種遮光條技術）。

👁️ 3. 它怎麼找到你的眼睛？

上面有一隻「小守衛眼睛」

  1. 📷 拍你的臉
  2. 🎯 找到兩個瞳孔
  3. 📐 算出兩眼在空間中的位置
  4. 🖼️ 馬上重畫一張給你這個角度看的圖
  • 第 3 代視線辨識感測器 已查證
  • 這代多加了紅外線（IR）感測器，暗暗的房間也能找到瞳孔 已查證
  • 依你看的位置即時產生立體影像 已查證
  • 它追的是眼睛「在哪裡」，不是你「在看什麼」：官方強調「瞳孔的位置」，合理但未明文 未查證

⚠️ 4. 它的小限制

一次只招待一位客人

  • 可看人數：1 人 已查證
  • 距離 30–80 公分；上下左右 25 度內 已查證
  • 每隻眼睛只分到一半的畫面細節（兩視點分畫素的推論） 未查證
  • 旁邊多人時只追一位、旁人看到疊影 未查證
  • 多人時怎麼選要追誰：官方沒說 未查證

就像說故事的阿公只看著一個小孩講，旁邊偷看的小朋友，看到的會有點糊糊、重影。
