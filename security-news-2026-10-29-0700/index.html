  • 10/28已遭利用 🐧CISA 再列兩個已遭利用漏洞：VMware ESX 與 Linux 核心「Fragnesia」 美國 CISA 10/28 把兩個漏洞加進已知遭利用漏洞（KEV）目錄：VMware ESX 的 CVE-2026-41709（記錄不足，攻擊者動手後不容易被查到），以及 Linux 核心提權漏洞 CVE-2026-46300（研究者稱 Fragnesia）。後者正是這次 PHP2Shell 攻擊鏈用來拿到 root 的那一環（見下方攻擊事件）。有 VMware 主機或 Linux 伺服器的，請優先排入更新。 🔗 CISA 官方公告（另見 The Hacker News、SecurityWeek 對 Fragnesia 的報導）↗
  • 10/28已有掃描試探 🗄️Oracle E-Business Suite 9.8 分漏洞剛修補，駭客已開始試探 Oracle 上週季度更新修了 E-Business Suite 的 CVE-2026-101767（CVSS 9.8）：不用登入就能對 /OA_HTML/AppsTCFServer 下 SQL 注入，再一路變成在主機上執行指令，可能碰到財務、薪資、人資、採購資料。發現者是 Horizon3.ai；誘捕系統業者 Defused Cyber 說 10/27 已記錄到試探性攻擊。用 EBS 的公司請立刻上修補。 🔗 The Hacker News（另見 BleepingComputer、SecurityWeek；引述 Horizon3.ai、Defused Cyber）↗
  • 10/28研究揭露 🔗ShinyHunters 用的 PeopleSoft 零時差，其實是三個漏洞串成 ShinyHunters（UNC6240）5/27–6/9 當成零時差、9 月又擴大利用（主要打大學）的 Oracle PeopleSoft 漏洞 CVE-2026-35273（9.8 分、已在 KEV），回報者 ZDI 這週公開細節：其實是三個不同漏洞串在一起，起點是伺服器端請求偽造（SSRF），讓外部請求能碰到只對本機開放的管理介面。Oracle 6 月已用單一編號修補，ZDI 正在幫每個漏洞另外申請 CVE。有 PeopleTools 8.61／8.62 還沒更新的，風險很高。 🔗 The Hacker News（引述 ZDI 分析、Mandiant／Google 威脅情報）↗
  • 10/28尚無穩定修補版 🧬藏了 16 年的 UEFI 韌體漏洞：網路開機時能在安全開機前執行程式 多數電腦廠商拿來做 UEFI 韌體的開源程式 EDK II，網路開機（PXE）程式碼有緩衝區溢位 CVE-2026-97631（TianoCore 評 9.5）。攻擊者只要在機器網路開機的短暫時間內、從同一個網路送出特製封包，就可能讓機器卡死，甚至在 Secure Boot 啟動前執行自己的程式。只從硬碟開機的家用電腦不受影響；主要是資料中心用網路開機的伺服器。修正程式碼已併入，但還沒有正式版本，要等各硬體廠商出韌體。 🔗 The Hacker News（另見 TianoCore 官方公告、Red Hat／SUSE 評級、@TheHackersNews）↗
  • 10/28後續・已修補 🔐Tailscale「Tailworm」後續：1.104.4 修好 SSH 轉送漏洞，headscale 仍未修 前幾天報過的 Tailscale SSH 問題，Tailscale 已推出 1.104.4 修補。前提是攻擊者已控制一台「政策允許 SSH 連過去」的裝置，就能利用轉送 Unix socket 時的時間差，摸到只有 root 才能碰的服務（研究者示範經 Docker socket 拿到 root）。有用 Tailscale SSH 的請更新；暫時不能更新，可設 TS_SSH_DISABLE_FORWARDING=1 關掉轉送。自架控制伺服器 headscale 的最新版 0.29.5 還沒修，這 4 份公告目前也都沒有 CVE 編號。 🔗 The Hacker News（引述 Tailscale 安全公告、Cyberdione Labs 報告）↗
  • 10/28研究報告（廠商自述） 🤖Anthropic 未發表模型自己串出 Chrome、Safari、Linux 等可用攻擊程式 Anthropic 前沿紅隊說，一個未公開的內部研究模型找到 Chrome、Safari、Android、Windows、Linux 的漏洞，並串成 5 條可用的概念驗證攻擊：例如在執行多路徑 TCP 的 Linux 伺服器上免登入拿到 root，或讓 Safari 網頁讀取其他已登入網站的資料。全部已先通報廠商並修補（Chrome 156、iOS 26.5.2、Linux 10/15 修補等），Anthropic 說回報給 Google 的 62 個 Chrome 漏洞都已修好。Google 的更新說明確實有致謝 Anthropic 與 Claude；但「模型幾乎自己完成」這點只有 Anthropic 自己的說法。請確認瀏覽器已更新到最新。 🔗 The Hacker News（引述 Anthropic 前沿紅隊報告；Chrome 更新說明可佐證）↗

  • 10/29資料已公開・來源未證實 🇺🇸美國國土安全部 4 萬多名員工資料被公開，含邊境與移民官員 TechCrunch 報導：自稱「Department of Peace」的駭客公開了美國國土安全部（DHS）超過 4 萬名員工的姓名、職稱、公務電郵、手機和辦公地點，其中約 2.1 萬人是海關邊境保護局（CBP）、約 1 萬人是移民及海關執法局（ICE），還有近 1,000 名 CISA 員工。駭客宣稱資料來自 DHS 的 Okta 單一登入系統——【未證實】：Okta 說自家系統沒被入侵，DHS 尚未回應。 🔗 TechCrunch（獨家，看過外洩資料；Okta 回應）↗
  • 10/28已證實 ✈️日本航空：訂位系統商 Amadeus 遭駭，9.2 萬名旅客資料外洩 日本航空（JAL）10/28 公告，訂位系統供應商 Amadeus 遭入侵，駭客存取了 JAL 和日本越洋航空的部分訂位資料，共 9.2 萬名旅客的姓名、訂位代碼、航班資訊外洩，其中約 2,000 人還有護照號碼、會員號碼、電郵和電話。信用卡沒外洩、航班正常。請小心冒用 JAL 名義的釣魚信和電話。 🔗 The Record（引述 JAL 官方公告；另見 @H4ckmanac）↗
  • 10/28已證實 🇲🇩摩爾多瓦政府系統遭大規模攻擊，約 75 萬人資料被撈 摩爾多瓦電子政府局說，駭客 10/19–10/23 利用政府服務的漏洞送出約 1,100 萬次查詢，撈走與約 75 萬個身分證號有關的資料，包括個人資料、社福給付、駕照和車籍資料，也可能有財務資料（銀行卡資料沒外洩）。總理 Tofan 說正在調查是否有外國政府介入，目前還沒點名任何國家。 🔗 The Record（引述摩爾多瓦總理、電子政府局 AGE）↗
  • 10/28部分證實 🇰🇷南韓金融業再遭一波攻擊：大信證券 3.8 萬名客戶資料外洩 南韓券商大信證券（Daishin）通報，3 萬 8,490 名客戶的資料外洩；未來資產（Mirae Asset）和加密貨幣交易所 Bithumb 也在 10/28 各自通報資安事件，但都沒證實客戶資料被偷。金融監管單位要求業者加強防護，這一波的原因還在調查。 🔗 TechCrunch（引述南韓當地媒體與監管單位）↗
  • 10/28後續・研究報告 🔥PHP2Shell 後續：疑中國駭客串連 Linux 提權，拿下 25 台防火牆、含美國政府相關單位 以色列資安公司 Dream 說，10/25 觀察到一起疑似中國背景、AI 輔助的攻擊：把 PHP2Shell（CVE-2026-109618／109619）和 Linux 核心提權漏洞 Fragnesia（CVE-2026-46300）串在一起，拿下 25 台某大廠防火牆的 root，其中 3 台在美國政府相關單位，之後再轉攻 Active Directory 網域。攻擊程式是針對該防火牆特製、未公開的版本。廠商名稱沒公布，Dream 已通知受害單位。 🔗 The Hacker News（另見 SecurityWeek；Dream 研究）↗
  • 10/28後續更新 💰GMO 雲端桌面遭駭後續：拒付勒索，改懸賞 100 萬美元抓駭客 日本 GMO 網路集團拒付勒索後，10/28 開辦「GMO Cybercrime Bounty」，總額最高 100 萬美元，只在線報促成逮捕或國際通緝（如紅色通緝令）時才付款，期限到 2027/10/27。攻擊者 10/27 公布的資料網站和鏡像站，已在日本時間 10/28 凌晨 4 點左右下線。 🔗 The Hacker News（引述 GMO 官方公告）↗
