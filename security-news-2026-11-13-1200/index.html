  • 11/12（美東）遭實際利用 🚨後續：N-able N-central 又爆新零時差，PoC 公開幾小時就遭利用，連已修補的伺服器也中招 前天報過的 Able2Shell 之後，研究員 Sean Bales 11/12 再公開兩個新漏洞「4EverAble2Shell」與「Agent2Shell」，前者可在 N-central 伺服器上免登入以 root 執行程式，後者可在 Windows 端取得 SYSTEM 權限，而且對 11/10 剛釋出的修補版 2026.4.1.26 依然有效。BleepingComputer 引述研究人員說，已有至少 21 台伺服器遭入侵並被裝上挖礦程式，其中 19 台跑的是最新修補版。N-able 表示問題要在開啟、且對外公開的 Legacy API（預設關閉）才會發生，雲端代管版不受影響，請立刻關閉 Legacy API。 🔗 BleepingComputer（另見 The Hacker News、SecurityWeek、N-able 公告）↗
  • 11/12零時差 PoC 🪟Windows「SignDrop」零時差攻擊程式公開，一般使用者可拿到 SYSTEM 權限，微軟尚未修補 化名 MSNightmare 的研究員在 11/10（Patch Tuesday 當天）於 GitHub 公開 SignDrop，濫用 Windows 11 25H2／26H1 與 Server 2025 在 CLFS 日誌系統新加的驗證功能：讓有權限的程序（範例用 Defender 更新介面）在攻擊者指定的位置建立檔案，進而從一般帳號提權到 SYSTEM。微軟尚未確認、沒有 CVE，也還沒有修補。CLFS 過去已有 10 個漏洞被列入 CISA 已遭利用清單，這類提權常被勒索軟體使用。 🔗 BleepingComputer（另見 The Hacker News）↗
  • 11/11～11/12嚴重修補 🌐Apache 網頁伺服器 HTTP/2 免登入遠端執行漏洞（9.8 分），由 Anthropic 與 Google 先後發現 CVE-2026-119618 是 mod_http2 模組的競態條件，影響 Apache HTTP Server 2.4.55～2.4.70，只有開啟 HTTP/2（Protocols 設定含 h2 或 h2c）的伺服器受影響，修補版為 2.4.71。Apache 致謝 Anthropic 的開源掃描工具 10/26 回報，Google 研究員 11/3 也獨立回報。Red Hat 評 9.8 分並稱有公開研究展示可靠攻擊；Wiz 則說目前沒有公開攻擊程式，也沒有實際遭利用。Wiz 統計 64% 的雲端環境有受影響版本。 🔗 SecurityWeek（另見 The Hacker News、BleepingComputer、Red Hat）↗
  • 11/12嚴重修補 📦Red Hat Quay 容器倉庫嚴重漏洞：不用帳號就能讀取、覆寫所有私有映像檔 Quay 預設允許匿名存取，攻擊者可把自己的金鑰加進 Quay 信任的簽章金鑰清單（且不會過期），之後就能讀出任何私有容器映像與其中的密鑰，甚至推送、覆寫映像，污染後續所有拉取它的系統；關掉匿名存取後，任何有效帳號仍可利用。同時揭露的另一個漏洞 CVE-2026-110697 為 9.9 分。Red Hat 已為 8 個 Quay 3 分支釋出修補。 🔗 The Hacker News（另見 SecurityWeek）↗
  • 11/12嚴重修補 🧰其他嚴重修補：Citrix NetScaler 認證繞過、MongoDB 免登入當機漏洞 Citrix 修補 NetScaler ADC／Gateway／Console 與 Secure Access Client 共 12 個漏洞，含可導致認證繞過的嚴重漏洞，表示是用 AI 輔助程式碼審查找到，目前沒有遭利用。MongoDB 修補 CVE-2026-118383（CVSS 4.0 評 9.5）：免登入即可讓複本集中落後的成員在切換主節點時當機，Atlas 會自動更新，自架的要每個成員都升級；MongoDB 稱未發現利用。 🔗 The Hacker News（Citrix 與 MongoDB 兩篇報導）↗

🔓入侵 / 資料外洩 / 供應鏈4 則

  • 11/10～11/13供應鏈攻擊 🐙駭客用 4,837 個被盜 GitHub 帳號，在 1,800 多個專案的 CI 裡植入密鑰竊取程式 Aikido Security 指出，攻擊者從 11/10 起用被盜帳號先開一個標題為「docs: dependency audit notes」的 PR 測試有沒有寫入權限（共 61,764 個專案收到），再把竊取程式塞進 CI 工作流程，至少在 1,806 個專案實際執行、偷走 CI 可取用的雲端憑證與密鑰；SafeDep 另統計 8,093 個公開專案收到惡意提交，其中 771 個是透過 npm postinstall，連開發者本機 npm install 也會中。攻擊者通常幾分鐘內就撤回修改並刪除執行紀錄。如果你的專案近日有不明 PR 或提交，請立刻輪換 CI 中的所有密鑰。 🔗 BleepingComputer（另見 The Hacker News、SecurityWeek；Aikido、SafeDep 研究）↗
  • 11/12公司證實 🇹🇼台積電證實部分現職與離職員工個資外流，來源是外部雲端服務商 台積電 11/12 向美國 SEC 申報，部分現職與前員工資料遭未經授權公開在外部網站；資料與某雲端服務商系統中的資料相符，目前沒有證據顯示台積電自己的系統遭入侵，也與營運和客戶資料無關，已通知受影響員工並與雲端廠商、調查機關及第三方資安單位合作。暗網賣家宣稱有約 4.6 萬筆、6.9GB，含身分證字號、住址、銀行資訊與緊急聯絡人，開價 3 顆比特幣，這些內容是賣家說法，台積電未證實；台積電未公布雲端商名稱。 🔗 台積電 SEC 6-K 申報（另見 Wccftech、TradingView／Seeking Alpha）↗
  • 11/11～11/12台灣相關 🏫歐洲數千所學校收到炸彈恐嚇信，寄件信箱是台灣大葉大學被盜的帳號 本週寄給歐洲數千所學校的炸彈恐嚇信，來自台灣大葉大學一個遭盜用的電子郵件帳號；中央社報導校方已停用該帳號。這是一連串利用真實機構被盜信箱寄送假恐嚇（先前也有機場、媒體與哥倫比亞波哥大衛生單位）的最新一波，因為是真信箱，能通過寄件驗證、躲過垃圾郵件過濾。Proofpoint 說部分特徵可能符合國家支持的駭客，但目前沒有任何政府正式歸因。 🔗 The Record（引用中央社、Proofpoint、Abnormal Security）↗
  • 11/12後續 🔐後續：Trezor 證實 3 台經銷商售出的 Safe 5 錢包被植入竊聽硬體，砍掉八成經銷商 先前報過的 CryptoBilis 案，Trezor 11/12 公布調查：3 台 8/20～9/23 經東南亞經銷商 CryptoBilis（含其 Tokopedia、Shopee 商店）售出的 Safe 5 被加裝電路板，會複製螢幕上顯示與輸入的助記詞，再經行動網路傳給攻擊者。11/11 的韌體 2.13.1 可讓這批植入物失效，但已被拍到的助記詞無法補救，CryptoBilis 買家仍應換新錢包與新助記詞；目前沒有客戶回報資金損失，其他經銷商與型號未發現問題。 🔗 Trezor 官方部落格（另見 Bitcoin.com News、Crypto Briefing）↗
