什麼是 Grok Bot

Grok Bot 是一個讓你擁有一整隊 AI 助理的 app。你可以建立好幾個 bot，每一個都有自己的對話、名字與個性，還有自己的記憶。它們會列在側邊欄，你點進去就能像傳訊息一樣交代事情。

和一般聊天機器人不同的是：每個 bot 都有自己的電腦可以寫程式、做檔案、上網查資料；也能透過連接服務（例如 Gmail、Google 日曆）替你處理事情；還能照排程自動工作，你不在的時候也一樣。

一句話記住

把每個 bot 想成一位有自己電腦的專職助理：用說話的方式交代，它做完會回報給你。

快速開始

先認識畫面上最常用的幾個地方，再照下面五個步驟開始。

  • 1側邊欄：你所有的 bot 都列在這裡，點一下就進入它的對話。
  • 2帳號按鈕（側邊欄左下角，頭像＋帳號名稱）：點它開啟設定。
  • 3聊天標題上的 bot 名稱：點一下開啟這個 bot 的資訊面板（快捷鍵 Cmd+Shift+I）。
  • 4資訊面板：上方是這個 bot 電腦的即時預覽（點它可看全螢幕），下方是它的 Routines（例行公事）列表。
  • 5面板標題列的 X 用來關閉面板；旁邊的齒輪是這個 bot 專屬的設定頁（頭像、名稱、職稱、描述、通知）。
  • 6對話區：在這裡打字交代事情，bot 的回覆、檔案、按鈕選項都會出現在這裡。

五個步驟開始使用

  1. 選一個 bot：在側邊欄點選，例如「網頁小工坊」。
  2. 像傳訊息一樣交代：直接用中文寫你要什麼、給誰看、什麼時候要。
  3. 回答它的問題：bot 有時會附上選項按鈕讓你點選，或先按個表情符號表示「收到」。
  4. 想看進度就打開資訊面板：看電腦即時預覽，必要時點開全螢幕幫忙（例如登入網站）。
  5. 確認後再送出：寄信、發訊息這類動作，bot 會先擬好草稿，由你決定是否按下傳送。
關於建立新 bot

你可以建立多個 bot，每個都有獨立的名字、個性與記憶。本說明書的參考資料沒有列出「新增 bot」按鈕的確切位置，所以這裡不寫點擊路徑；找不到的話，直接問任一個現有的 bot 就好。

Bot 的電腦

每個 bot 都能使用一台 Linux 電腦，有瀏覽器和桌面。它在這台電腦上執行程式、製作檔案（試算表、圖片、網頁…）、上網查資料。這台電腦是 bot 們共用的同一台機器，但每個 bot 有自己的桌面畫面。

怎麼看 bot 正在做什麼？

點聊天標題上的 bot 名稱（或按 Cmd+Shift+I）打開資訊面板，最上方就是它電腦的即時預覽；點一下預覽會開啟全螢幕畫面。遇到需要你親自輸入帳密或驗證碼的網站時，你可以在那裡接手幫忙。

電腦卡住了？

到 設定 → Computer → Update Grok Bot's Computer，按 Update，再按一次 Click Again to Confirm。它會把電腦搬到新的環境，保留檔案與登入狀態，但安裝過的軟體需要重新安裝。

下方的 Reset 是最後手段：會還原到上次的快照，可能遺失最近的工作，請優先用 Update。

連接服務

「連接服務」（Connectors）讓 bot 能用你的帳號操作各種服務，例如讀信、查行事曆、在雲端硬碟建立文件、在 GitHub 發布網頁。連接之後，bot 就能代表你使用這些服務。

📬 Gmail

郵件小幫手每天用它找帳單與繳費通知。也可以請 bot 搜尋信件、幫你擬回信草稿。

📅 Google 日曆

查行程、找空檔、安排活動。

📁 雲端硬碟・文件・簡報

把整理好的內容存成 Google 文件或簡報、讀取你雲端上的檔案。

🛠 GitHub・Cloudflare

網頁小工坊用 GitHub 發布網頁；Cloudflare 可用於網站相關的工作。

怎麼新增連接？

本說明書的參考資料沒有列出新增連接服務的確切選單，所以不寫點擊路徑。若有可用的「頻道」類連接服務，bot 的資訊面板會出現 Channels 區塊。不確定時，直接問 bot：「我要怎麼連接 Google 日曆？」

例行公事（Routines）

Routine 是存起來的指令，會依排程或在某些事件發生時自動執行——就算你不在，bot 也會照常工作，做完再回報。

  • 約 05:52　郵件小幫手檢查 Gmail，找出帳單與繳費通知。
  • 09:08　清理例行公事：清掉超過保存期限、沒有標記保留的網頁。
  • 每天　每日摘要：例如把新聞或待辦整理成一則重點訊息。
  • 事件觸發　當某件事發生時自動執行，不必等固定時間。
在哪裡看？怎麼建立？

每個 bot 的 Routines 列在它的資訊面板裡（點聊天標題上的名稱打開）。想新增，直接用一句話跟 bot 描述就好，例如：「每天早上 8 點提醒我看今天的行程」。

記憶與技能

🧠 記憶

Bot 會記住你的偏好，下次不用再交代。例如它記得你習慣用手機看網頁，所以做出來的網頁都是手機優先排版。

想讓它記住什麼，直接說：「記住：…」。

🧰 技能

技能是可重複使用的固定流程，存起來後所有 bot 都能用。適合「每次都要照同樣步驟做」的事情。

安全與授權

Bot 會幫你把事情準備好，但對外送出的最後一步由你決定。寄信、傳訊息時，bot 會先擬好草稿，讓你檢查後自己按「傳送」；有風險的動作則需要你批准。

放心交代

你可以說「幫我回信給房東」，bot 會準備好草稿；真正寄出前，決定權都在你手上。

相關設定

設定的 General 分頁裡有 Auto-review（自動審查）與其規則，以及 Security keys（安全金鑰）等安全相關項目。部分項目只會出現在某些帳號或版本。

介面與設定導覽

打開設定的三種方法

  1. 點側邊欄左下角的帳號按鈕（頭像＋帳號名稱）。
  2. 按快捷鍵 Cmd+,。
  3. 在指令面板（command palette）選 Open settings。
沒有齒輪圖示

全域設定沒有齒輪按鈕，也沒有 macOS 的「偏好設定」選單項目。（資訊面板裡的齒輪是單一 bot 的設定，不是全域設定。）

設定的四個分頁

  • ⚙️ General（一般）
    • 帳號卡片（登入／登出）
    • Theme 主題：Follow System／Light／Dark
    • Language 語言、拼字檢查、麥克風
    • 通知音效、時區（timezone）
    • Auto-review 與規則、Security keys
  • 💻 Computer（電腦）
    • 已登記的電腦（registered machines）
    • Update Grok Bot's Computer：按 Update → Click Again to Confirm。保留檔案與登入，軟體需重裝。優先用這個
    • Reset Grok Bot's Computer：還原到上次快照，可能遺失最近的工作。最後手段
  • 💳 Usage & Billing（用量與帳務）
    • 用量與方案相關設定。只在帳號有開放時才會出現。
  • ⬆️ Updates（更新）
    • Update Track：Stable／Nightly
    • Check for Updates：更新 Grok Bot app 本身（和「更新 bot 的電腦」是兩回事）

單一 bot 的資訊面板

點聊天標題上的 bot 名稱（或 Cmd+Shift+I）打開，用面板標題列的 X 關閉。裡面有：

  • 這個 bot 電腦的即時預覽（點一下開全螢幕）
  • Routines 列表
  • Channels（有可連接或已連接的頻道類連接服務時才出現）
  • Members（群組對話中才出現）
  • X 旁的齒輪 → 這個 bot 的設定頁：頭像、名稱、職稱、描述、個別通知

刪除 bot

在側邊欄對該 bot 按右鍵 → 選 Delete，確認後完成。

刪除是永久的

會一併刪除這個 bot 和它的所有對話紀錄，沒有封存或隱藏的選項。刪除功能不在設定裡。

部分設定列只會出現在某些帳號、版本或狀態下。找不到某一項時，通常代表你的帳號目前沒有它。

常見問題

找不到設定的齒輪按鈕？

全域設定沒有齒輪。請點側邊欄左下角的帳號按鈕、按 Cmd+,，或在指令面板選 Open settings。

怎麼改 bot 的名字或頭像？

點聊天標題上的 bot 名稱打開資訊面板 → 按 X 旁邊的齒輪 → 在 bot 設定頁修改頭像、名稱、職稱、描述與通知。

怎麼刪除 bot？可以封存嗎？

在側邊欄對 bot 按右鍵 → Delete，確認後永久刪除（連同對話紀錄）。沒有封存或隱藏功能。

Bot 的電腦卡住或怪怪的？

到 設定 → Computer → Update Grok Bot's Computer，按 Update 再按 Click Again to Confirm。檔案與登入會保留，軟體需重新安裝。除非真的沒辦法，避免使用 Reset。

「Check for Updates」和「Update Grok Bot's Computer」差在哪？

Check for Updates（在 Updates 分頁）更新的是 Grok Bot app 本身；Update Grok Bot's Computer（在 Computer 分頁）是把 bot 的電腦換到新的環境。

我不在的時候，例行公事會跑嗎？

會。Routines 依排程或事件執行，你不在也照常進行，做完會回報給你。

網頁小工坊做的網頁會一直留著嗎？

預設 10 天後自動刪除。要保留，跟網頁小工坊說「這頁幫我保留」。

Bot 會不會自己幫我寄信？

不會。它會先擬好草稿，由你檢查後按下傳送；有風險的動作也會先請你批准。

可以看到 bot 在電腦上做什麼嗎？

可以。打開資訊面板就有電腦即時預覽，點一下可以全螢幕觀看；需要登入時你也能在那裡協助。

某個設定我找不到？

有些設定列只出現在部分帳號、版本或狀態（例如 Usage & Billing 只在帳號有開放時才出現）。找不到通常代表你的帳號目前沒有這一項。
